A linked list gives every node one successor. Allow two, and you get a structure whose height is logarithmic in its size when it is balanced, and that is the whole reason trees exist: any operation that walks one root-to-leaf path costs O(log n) instead of O(n). Search trees, heaps, tries, B-trees, segment trees, syntax trees and every hierarchical namespace you have used are variations on that one idea.

Trees are also the first structure where recursion stops being a curiosity and becomes the only sane way to write code. A tree is a node plus two smaller trees; almost every tree algorithm is "solve the two smaller trees, then combine". Interviewers love trees because they test whether you can define a recursive contract precisely, and senior interviewers push further: what happens when the tree is degenerate, when the recursion is 100,000 frames deep, or when the tree lives on disk in 16 KiB pages.

This module builds from terminology and the four ways to lay a tree out in memory (with the bytes per node in CPython, Java and Rust, and what a pointer hop costs against the cache), through the four traversals with their stack states traced step by step, Morris traversal and how `TreeMap` and the DOM iterate without a stack; binary search trees with insert, delete and validation traced on one tree, the sorted-input chain and what the random-order numbers really are; why and how trees are kept balanced, with every AVL rotation case worked, the red-black rules through their 2-3-4 correspondence, and B-trees as the same idea sized to a disk page; the top-down and bottom-up recursion patterns that cover the whole interview problem family, with the return value at every node tabulated; and finally general n-ary trees, the serialisation formats that can and cannot be decoded, and the file systems, Git object stores and JSON parsers that are n-ary trees in production. The [balanced trees](/learn/advanced-data-structures/balanced-trees/avl-trees) and [range queries](/learn/advanced-data-structures/range-queries/segment-trees) modules in the advanced track pick up where this one stops.
