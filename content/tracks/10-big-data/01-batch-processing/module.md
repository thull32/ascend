Batch processing is the part of big data that looks simple from the outside: read a lot of files, transform them, write a lot of files. Inside, every decision is about moving bytes across a network as few times as possible. The shuffle (regrouping data by key across machines) is the single most expensive thing a distributed job does, and most of what separates a job that runs in ten minutes from one that runs in ten hours is how many shuffles it does and how evenly the keys spread.

This module starts with MapReduce because its constraints (two phases, a disk write between them) make the shuffle visible: you trace a word count through the sort buffer, spill files and segment fetches by hand, and watch what a dead worker costs. It then moves to Spark, where the same shuffle hides behind a DataFrame API and you have to know it is there, in the shape of stages, tasks, one data file and one index file per map task, spill, and the adaptive rules that split a skewed partition. The storage lessons cover what HDFS and S3 actually guarantee, down to the write pipeline, checksums and the commit protocols that do or do not work on an object store; how Parquet lays out a row group, a column chunk and a page in bytes so that a selective query moves a few megabytes out of a 512 MB file; and how table formats like Iceberg and Delta turn a directory of files into something with atomic commits, snapshots and safe schema evolution. The module closes with OLAP engines, where columnar storage, a sparse index and vectorised execution meet interactive latency.

Every lesson carries the numbers and the failure modes an interviewer will push on: the default that spills, the key that skews, the small files that choke a NameNode or an S3 bill, the rename that is a copy, the delete that does not delete, the insert pattern that produces too many parts. By the end you will be able to look at a Spark plan, a Parquet footer, an Iceberg commit or a ClickHouse table definition and predict, in bytes and partitions, why it is slow and what to change.
