@0
An 8 by 8 matrix stored row by row, so each row is exactly one cache line of 8 elements. The cache on the right holds just 4 lines. The one fact that drives everything here: memory is fetched in whole lines, never single elements, so touching one element pulls its 7 neighbours in with it. We walk the matrix along its rows, elements 0 to 39.

@1
Element 0 is not cached: a miss. The whole of line 0, elements 0 to 7, comes in from memory into slot 0. A miss costs roughly a hundred times what a hit does, but it bought us 8 elements, not one.

@2-8
Elements 1 through 7 all live in line 0, which is already in slot 0. Seven hits in a row, each served in a few cycles.

@9-16
Element 8 starts line 1, so that is a miss, and line 1 lands in slot 1. Then elements 9 to 15 are seven more hits.

@17-32
The same rhythm for lines 2 and 3: one miss to fetch the line, seven hits to use it. Now all 4 slots are full.

@33-34
Element 32 is in line 4, which is not cached, and there is no free slot. The least recently used line, line 0, is evicted from slot 0, and line 4 takes its place. That eviction costs nothing here, because we had already finished with every element of line 0.

@35-41
Elements 33 to 39 are hits in line 4.

@42
Forty accesses: 35 hits and 5 misses. Every element of every fetched line was used before moving on. Hold that number, because the next animation walks exactly the same matrix in a different order.
