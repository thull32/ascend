@0
A small array of 32 elements, which is exactly 4 cache lines of 8, and a cache that holds 4 lines. A loop reads one element from each line, elements 0, 8, 16 and 24, and the benchmark runs that loop three times. The thing to watch is how different the first pass is from the rest.

@1-4
First pass. Element 0 misses and line 0 is fetched from memory. Element 8 misses and line 1 comes in, then line 2 for element 16, and line 3 for element 24. Four accesses, four misses, each roughly a hundred times the cost of a hit. The cache is now full, and holds all of the data.

@5-8
Second pass. Element 0 is in line 0, already cached: a hit, served in a few cycles. Then 8, 16 and 24: all hits.

@9-12
Third pass, and the same: four hits.

@13
Twelve accesses, 8 hits, 4 misses, and every miss was in the first pass. The first iteration is cold, the rest are warm. A benchmark that runs the loop many times and reports the average or the median reports the warm number. Production sees that number only if its data stays hot between requests. Decide which one you are measuring, and if production starts cold, measure cold.
