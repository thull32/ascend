@0
On the left is a thread's stack, on the right the process's heap. The rule to hold onto: a stack frame belongs to the thread that pushed it and disappears when its function returns, while anything on the heap lives until someone frees it, and every thread in the process can reach it. Here main has just started. Its locals, n equal to 3 and list, which is still null, live in main's stack frame.

@1
Main calls build with n. A new frame goes on top of the stack, with its own n, its own head and a loop counter i. Build's locals are separate from main's, even though both have something called n.

@2-4
The loop runs three times. Each iteration allocates a node on the heap, first at address 1000 holding 4, then at 1020 holding 8, then at 1040 holding 15, and head moves to the newest one. Each new node's next field points at the one before it, so the list now runs 15, 8, 4. None of these nodes belongs to build's frame.

@5
Build returns head. Its frame is popped and its locals vanish, but all three nodes survive, because heap memory is released by an explicit free, not by leaving a scope. Main's list now holds address 1040.

@6
Main calls print with the list. Print's frame gets its own copy of the pointer, so two frames now hold the same address. Copying a pointer copies the address, not the object. This is exactly how two threads come to share data: they each hold a pointer into the same heap.

@7
Print returns and its frame is discarded. The heap is unchanged.

@8-10
Now main tears the list down, one node at a time: 1040, then 1020, then 1000. Before each free, main advances list to the next node; free first, and it would lose its only path to the rest of the list, which would leak.

@11
Main returns: the stack is empty and every heap block has been freed. This picture follows a single thread, but the lesson's point carries straight over. A second thread would get its own stack, its own frames and locals, and would see exactly the same heap. That shared heap is what makes threads cheap to communicate through, and it is also what makes races possible.
