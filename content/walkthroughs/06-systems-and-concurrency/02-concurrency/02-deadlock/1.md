@0
Three threads and three locks, A, B and C. T1 takes A and then B. T2 takes B and then C. T3 takes C and then A. Each thread takes its two locks in a different order, and that is the trap.

@1
All three take their first lock at the same moment. T1 holds A, T2 holds B, T3 holds C.

@2
Now nobody can move. T1 wants B, but T2 holds it, so T1 blocks, still holding A. T2 wants C, which T3 holds, so it blocks holding B. T3 wants A, which T1 holds, so it blocks holding C. The wait-for graph is a cycle: T1 waits for T2, T2 for T3, and T3 for T1. Each thread is waiting for a lock that only a waiting thread can release, so none ever will.

@3
All four Coffman conditions hold here. Mutual exclusion: a lock has one owner. Hold and wait: each thread keeps the lock it has while waiting for the next. No preemption: nobody can take a lock away. And circular wait: the cycle you just saw. Break any one of the four and deadlock becomes impossible.

@4
The usual fix breaks circular wait with a global lock order: every thread takes the alphabetically smaller lock first. So T3 now takes A before C. Here is the same start, replayed with that rule.

@5
T1 takes A and T2 takes B. T3 wants A first now, but T1 holds it, so T3 blocks while holding nothing at all. That detail is the point.

@6-8
T1 wants B and blocks behind T2, still holding A. But T2 is free to take C, because nobody who holds C is waiting on anything. T2 holds B and C, does its work, and releases both.

@9-11
T1 now takes B, works while holding A and B, and releases both. T3 finally gets A.

@12-14
T3 takes C, does its work while holding A and C, and releases them.

@15
Every thread finished. With a total order on locks, no cycle can form, because a thread waiting for some lock only ever holds locks that come earlier in the order, so the chain of waiting always ends at a thread that can run. The other options are a try-lock with backoff, or one coarse lock. And remember the window is tiny: the lesson's Go version deadlocked after a few thousand transfers in a hot loop, and in production it takes a week.
