@0
The array is 4, 1, 2, 1 and 2. Every value appears twice except one. Three properties of XOR find it: XOR of any number with itself is 0, XOR of any number with 0 is the number itself, and the order of the operations does not matter. So combining the whole array with XOR cancels every value that appears an even number of times.

@1
The accumulator starts at 0. XOR in 4, and it becomes 4.

@2
XOR in 1. Four is 1 0 0 and one is 0 0 1. They differ in two columns, so the accumulator becomes 1 0 1, which is 5.

@3
XOR in 2, and the accumulator becomes 1 1 1, which is 7. At this point it holds 4, 1 and 2 all mixed together.

@4
Now the second 1 arrives. Its bit was already set, so XOR turns it off: the accumulator drops to 6. The two 1s have cancelled.

@5
Then the second 2 does the same, and the accumulator is 4. The pairs cancelled even though they were not next to each other.

@6
The final answer is 4, the value that appears an odd number of times. Linear time, constant extra space, and no hash set. The same idea finds a missing number in a range, and with one more split by a differing bit, it finds two singletons.
