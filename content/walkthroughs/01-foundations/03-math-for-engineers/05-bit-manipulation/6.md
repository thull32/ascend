@0
With three items, 1, 2 and 3, a three-bit number names one subset. Bit 0, the rightmost column, says whether the first item is in, bit 1 the second, and bit 2 the third. Counting from 0 to 7 therefore visits all 8 subsets, with no recursion at all.

@1
Mask 0 is 0 0 0. No bits set: the empty subset.

@2-3
Mask 1 is 0 0 1. Only bit 0 is set, so the subset is just the item 1. Mask 2 is 0 1 0, bit 1, so the subset is just 2.

@4-5
Mask 3 is 0 1 1, bits 0 and 1, so the subset is 1 and 2. Mask 4 is 1 0 0, only bit 2, the subset holding 3.

@6-7
Mask 5 is 1 0 1, bits 2 and 0, so the subset is 1 and 3. Mask 6 is 1 1 0, bits 2 and 1, the subset 2 and 3.

@8
Mask 7 is 1 1 1, every bit set: the full set.

@9
All 8 subsets, visited in order of the integers, in time proportional to 2 to the n. There is a bonus: every proper subset of a mask is a smaller number than the mask, so walking the masks upward is a valid order for subset dynamic programming. Every subset is solved before any set that contains it.
