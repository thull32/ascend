@0
A power of two has exactly one set bit. And n AND n minus 1 clears the lowest set bit. Put those together: for a power of two, clearing its only bit leaves zero, and for anything else, some other bit survives.

@1
Take 16. In 8 bits it is 0 0 0 1 0 0 0 0: a single set bit.

@2
Subtract 1 and you get 15, which is 0 0 0 0 1 1 1 1. The subtraction borrows: the lowest set bit flips to 0, and every bit below it flips to 1.

@3
Now AND 16 with 15. No column has a 1 in both, so the result is 0. The only set bit was cleared, and 16 is a power of two, 2 to the 4th.

@4
Now 18, which is 0 0 0 1 0 0 1 0. Two set bits.

@5
Subtract 1 to get 17, which is 0 0 0 1 0 0 0 1. Again, the lowest set bit flipped to 0 and the bit below it flipped to 1, but the higher bit, worth 16, was untouched.

@6
18 AND 17 is 16. Not zero: a higher bit survived, so 18 is not a power of two.

@7
The test is one subtraction, one AND and one comparison, with no loop over the bits. One guard from the lesson: zero AND minus one is also zero, so check that n is positive first.
