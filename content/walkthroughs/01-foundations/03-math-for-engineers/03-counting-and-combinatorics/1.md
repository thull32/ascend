@0
We want every subset of 1, 2 and 3. The counting argument is one sentence: each item is either in or out, two choices, three times, so 2 times 2 times 2 is 8 subsets. The recursion tree makes that sentence literal. Each level decides one item, so the tree is binary and has 8 leaves.

@1-4
Start at the empty set and always try "include" first. Include 1, include 2, include 3. All three decisions are made, so we record the full set, 1, 2, 3, as subset number 1.

@5-6
Back up one level, to the set holding 1 and 2, and take the other branch: leave 3 out. That records 1 and 2 as subset number 2. Notice that every leaf sits at the same depth, three decisions down.

@7-12
The node that decided 3 is finished, so we return to the node holding just 1 and take "exclude 2". Then the decision about 3 again: include it, giving 1 and 3, and exclude it, giving 1 alone. Subsets 3 and 4.

@13-15
Every subset containing 1 is done: four of them, half the total. We climb all the way back to the empty root and take its other branch, "exclude 1".

@16-21
The right half mirrors the left. Include 2, then include 3, giving 2 and 3. Exclude 3, giving 2 alone. Subsets 5 and 6.

@22-26
Back at the empty set with 1 and 2 both excluded, one decision is left. Include 3 gives the set holding only 3, subset 7. Exclude it, and we record the empty set as subset 8. The empty set and the full set are both leaves, and both count.

@27-30
The recursion unwinds to the root. Eight subsets, 2 to the power 3, from 15 calls: the 8 leaves plus the 7 decision points above them. The number of leaves doubles with every item you add, while the stack depth only grows by one. Twenty items is about a million subsets, a plain loop. Forty items is about a trillion, and that is when you reach for meet-in-the-middle.
