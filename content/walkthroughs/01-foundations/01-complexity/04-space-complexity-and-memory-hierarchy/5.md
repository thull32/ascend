@0
Five numbers: 0, 1, 0, 3 and 12. The job is to move every non-zero value to the front, keeping their order, with the zeros at the end, and without a second array. Two pointers move in the same direction: a read pointer visits every element, and a write pointer, w, marks where the next non-zero belongs.

@1
Position 0 holds a zero. Skip it; w stays at 0.

@2
Position 1 holds 1, which is non-zero. Swap it into position 0, where w points, and move w forward to 1.

@3
Position 2 is another zero. Skip it.

@4
Position 3 holds 3. Swap it into position 1, and w moves to 2.

@5
Position 4 holds 12. Swap it into position 2, and w moves to 3.

@6
The array is now 1, 3, 12, 0, 0. Every non-zero moved forward in its original order, and the zeros trail behind. The write pointer only ever trails the read pointer, so nothing is overwritten before it has been read. One pass, order n time, and constant extra space: the space you saved is the second array you never allocated.
