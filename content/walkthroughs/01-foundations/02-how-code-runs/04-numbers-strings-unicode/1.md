@0
An 8-bit word, signed, in two's complement. A shift moves every bit sideways by some number of positions. A left shift fills the right with zeros, and whatever falls off the left end is simply lost. Keep the range in mind: 8 signed bits hold minus 128 up to 127, and nothing outside it.

@1
x is 5, which is 0 0 0 0 0 1 0 1.

@2-3
Shift left by one and the pattern becomes 0 0 0 0 1 0 1 0, which is 10: exactly 5 times 2. Shift left by two and it is 20, 5 times 4. Each left shift doubles, as long as the answer still fits.

@4
Shift right by one and the low bit, a 1, is dropped. The result is 2, which is 5 divided by 2, rounded down. A right shift is floor division by 2.

@5
Now x is minus 5: 1 1 1 1 1 0 1 1. The top bit is set, and in two's complement the top bit is worth minus 128, which is what makes the number negative. You get this pattern from 5 by flipping every bit and adding one.

@6-7
Shift minus 5 left by one: 1 1 1 1 0 1 1 0, which is minus 10, exactly minus 5 times 2. By two, it is minus 20. A 1 fell off the top each time, but it was only a copy of the sign bit, so no value was lost. Doubling a negative number is not overflow, as long as the answer stays at or above minus 128.

@8
Right shifts are where signed numbers get interesting. An arithmetic right shift copies the sign bit into the top, giving 1 1 1 1 1 1 0 1, which is minus 3. That is minus 5 over 2, rounded down, so the floor division still holds.

@9
A logical right shift fills the top with a zero instead: 0 1 1 1 1 1 0 1, which is 125, a large positive number. Same bits in, two very different answers out, and languages differ on which one the right shift operator means for signed values.

@10
Last, x is 127: 0 1 1 1 1 1 1 1, the largest value this word can hold.

@11
Shift it left by one and the result is 1 1 1 1 1 1 1 0. The 1 that slid into the sign position makes it read as minus 2, not 254. 254 does not fit between minus 128 and 127, so the result wraps. That is overflow, and no circuit checked anything: the bits simply moved.

@12
Shift left by two and it is 1 1 1 1 1 1 0 0, which reads as minus 4 instead of 508. Overflow again.

@13
Shifting 127 right by one gives 63, which is 127 over 2, rounded down.

@14
Shifts take constant time, and they are how multiplying and dividing by powers of two, bit masks such as 1 shifted left by k, and packed fields are built. The trap is at the edges: a left shift whose true answer does not fit in the word, and a right shift whose meaning for negative numbers depends on the language.
