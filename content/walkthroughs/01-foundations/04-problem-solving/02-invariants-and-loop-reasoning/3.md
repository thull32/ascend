@0
A sorted array with duplicates: 1, 1, 2, 3, 3, 3 and 5. We compact it in place. A read pointer visits every element, and a write pointer marks where the next distinct value goes. The invariant that makes this safe: the write pointer never passes the read pointer, and everything before the write pointer holds the distinct values seen so far, in order.

@1
The read pointer starts on the first 1. It is new, so it is written at position 0.

@2
The second 1 duplicates the last value kept. Skip it. The read pointer moves on; the write pointer waits at position 1.

@3
The read pointer reaches 2, which is new, and it is written at position 1, overwriting the duplicate 1. That overwrite is safe precisely because the write pointer is behind the read pointer: the slot it clobbers has already been read.

@4
Next is 3, also new, written at position 2.

@5-6
The next two 3s duplicate the last kept value. Both are skipped, and the read pointer pulls ahead while the write pointer stays at position 3.

@7
Finally 5, which is new, is written at position 3.

@8
The first four slots hold 1, 2, 3 and 5, the distinct values in order, and the rest is leftover. One pass, linear time, constant extra space. If the write pointer could ever overtake the read pointer, a write could destroy a value not yet read, and the invariant is exactly what rules that out.
