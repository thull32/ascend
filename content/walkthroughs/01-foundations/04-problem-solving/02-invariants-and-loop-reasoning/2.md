@0
Binary search for the first true is about a monotone predicate: false, false, false, then true from some point onward. Here the array is 0, 0, 0, 1, 1, 1, and the predicate asks whether a value is at least 1, so it is exactly the lesson's flags: false three times, then true. The invariant: every index below low is false, and every index at or above high is true. The unknown region runs from low up to, but not including, high: here 0 to 6. High starts at 6, one past the end, because before we look at anything, the only index known to be true is the imaginary one past the end.

@1
The middle of 0 to 6 is position 3, which holds 1: true. Everything from position 3 onward is true, so high moves to 3. A true probe keeps the middle in range, because it might be the answer.

@2
The unknown region is now 0 to 3, and its middle is position 1, which holds 0: false. Everything up to position 1 is false, so low moves to 2, one past the middle. A false probe excludes the middle, because it is definitely not the answer.

@3
The region is 2 to 3, and its middle is position 2: false again. Low moves to 3.

@4
Low equals high, so the unknown region is empty and the loop stops. The answer is low, which is 3: the first true. Every step shrank the region and kept the invariant, so at exit there is nothing left to be unsure about. And if the array held no true at all, low would climb to 6, the length of the array, the insertion point. Starting high at the length instead of the length minus 1 makes that case fall out for free, and that is the payoff of choosing the half-open range.
