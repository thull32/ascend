@0
Forty readers, the app servers, a cache, and a database behind it. One hot key, the feed, lives in the cache with a time to live of 2 seconds, and the database is sized for about one query a second on it. This is a cache stampede: the moment that key expires, every concurrent reader misses at once.

@1
The time to live runs out, and the key vanishes, while 40 requests a second are still asking for it.

@2-4
Forty requests arrive in the same instant. All of them check the cache, and all of them miss, because nobody has put the value back yet.

@5
So every one runs the expensive query. The database gets 40 at once instead of one. Its latency climbs from 5 milliseconds to seconds of queueing, the connection pool drains, and unrelated queries stall behind them.

@6
Eventually all 40 return the same rows and all 40 write the same value back. Thirty-nine were wasted, and cascading failures often start exactly here. At a CDN this is the same picture with the origin in place of the database, and it recurs at every expiry of a hot object.

@7
The first fix is request coalescing, also called single flight: the first request to miss takes a short lock on the key, and everyone else waits on its result.

@8
One request wins the lock with a set-if-not-exists that expires after 500 milliseconds. The other 39 see the lock and wait briefly, or serve a stale copy if one exists.

@9
Only the lock holder queries the database.

@10
It writes the fresh value, releases the lock, and the waiters read it from the cache. One query instead of 40. A CDN does the same thing per point of presence, and a shield tier behind the edges collapses the remaining one-per-PoP fetches into one.

@11
Two more defences. Keep serving the stale value while a single background refresh runs, which is stale-while-revalidate. And add jitter to expiry times, so many keys never expire in the same second.

@12
Each fix has a cost. The lock adds a round trip and a short wait on every miss, and serving stale means readers briefly see an old value. Both are far cheaper than an origin that falls over under 40 times its normal load.
