@0
The task on this panel reads "Summarise what's new in my inbox today", but the steps that follow are the stock agent example: two tools, list PRs and today, counting old pull requests. Treat it as the shape of any agent loop, and watch for one thing: which side of the loop each step happens on. The model only proposes; the harness decides and executes.

@1
Iteration 1. The model emits a structured call, list PRs with state open. A proposal, nothing more. This is the point to check the proposal against an allowlist before anything runs.

@2
The harness executes the call. Every control that must hold, whatever the model has read, lives on this side: allowlists of tools and recipients, argument validation, sandboxing, and confirmation before an irreversible or outbound action.

@3
The result is appended to the transcript: 12 pull requests with their dates. This is the dangerous moment in general. Every observation becomes input to the next decision, and if a tool result contains attacker-written text, that text now sits in the same token stream as your instructions. From here, the session should count as tainted.

@4
Iteration 2. The model proposes another call, today.

@5
The harness executes it.

@6
The result, a date, is appended.

@7
Iteration 3. The model writes its final reply, an answer about 4 old pull requests, and the loop ends. That reply now goes to a renderer, and the renderer is outside the loop. In the lesson's email attack, a team restricted the send tool and forgot the renderer: a Markdown image in the reply made the browser fetch an attacker's address with the stolen link in it.

@8
The loop's own guards are an iteration cap, here 6, a token budget, tool timeouts, and human confirmation for irreversible actions. The security guards sit beside them, on the harness side: taint tracking, so that after reading untrusted content every outbound action needs approval, and controls on the renderer, such as blocking remote images. Remove at least one leg of the lethal trifecta in every context: private data, untrusted content, and a way to send data out.
