Prefill runs the prompt, The cat sat, through the model in one pass, computing a key and a value for every prompt token in every layer: three pairs here, thousands for a real system prompt. Keep your eye on this frame, because this prefill work is exactly what a prompt cache hit skips.

Decode step 3 adds mat: 6 pairs cached, 18 without. These frames show the cache inside one request. Prompt caching extends the same idea across requests: the provider keeps the keys and values of a byte-identical prefix, so the next turn of a conversation prefills only its new tokens.

@4
The cache costs memory, about half a megabyte per token for a 7-billion-class model in 16-bit, and a provider keeps a cached prefix for a limited time, 5 minutes on the lesson's Anthropic figures, refreshed on each hit. The billing follows the mechanism: writing the cache costs 1.25 times the input price and a hit costs a tenth of it on most models. And the rule that breaks it: one changed byte invalidates everything after it, so static content goes first and anything volatile, such as a timestamp or a user's name, goes last.
