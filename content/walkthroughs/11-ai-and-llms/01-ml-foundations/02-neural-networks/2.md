@0
The same network after its forward pass. The hidden units read 0.4, 0.5 and zero, and the output is 0.53. The correct answer is 1, so the cross-entropy loss is 0.63. Backpropagation finds, for every weight, how much the loss would change if that weight moved, starting at the output and walking backwards. Every step has the same shape: the error arriving from above, times the local derivative.

@1
Start at the output. With a sigmoid output and cross-entropy loss, the derivative collapses to something beautifully simple: the prediction minus the target. 0.53 minus 1 is minus 0.47. Negative means the output should be larger.

@2
Each output weight's gradient is that error times the activation feeding it. For the first hidden unit, minus 0.47 times 0.4 is about minus 0.19. For the second, about minus 0.23. For the third, zero, because a unit that was off contributes no gradient to its weight. The output bias gets the error itself, minus 0.47.

@3
Now push the error back into the hidden layer. Each hidden unit receives the output error times its own outgoing weight, then passes through its ReLU gate. Unit 1, weight 0.7, gets minus 0.33. Unit 2, weight minus 0.5, gets plus 0.23: it is dragging the output down, so the sign flips. Unit 3 was off, its gate is closed, and nothing flows through it.

@4
Each first-layer weight's gradient is the hidden unit's error times the input on that edge. Unit 1's weights get about minus 0.33 and minus 0.16, half as much on the second edge because that input was only 0.5. Unit 2's get 0.23 and 0.12. Unit 3's get zeros. That is the chain rule, applied layer by layer.

@5
Update every parameter by stepping against its gradient, with a learning rate of 0.5. The first output weight rises from 0.70 to 0.79, and unit 1's first incoming weight rises from 0.50 to 0.66, so unit 1 now fires harder, at 0.77. Unit 2's weights fall, and it drops to 0.24. Unit 3's incoming weights do not change at all.

@6
Run the forward pass again: the prediction climbs from 0.53 to 0.65, and the loss falls from 0.63 to 0.43. One step moved the network towards the right answer. The backward pass costs about twice the forward one, and frameworks build this chain automatically for billions of parameters. The trap to remember is unit 3: a ReLU that is off receives no gradient, and if it is off for every input it never recovers. That is a dead unit.
