@0
Remove the 2nd node from the end of 1, 2, 3, 4, 5, in one pass. Two pointers, fast and slow, both start on a dummy node in front of the head. The dummy makes removing the head itself an ordinary case.

@1-2
First, open the gap. Fast advances alone, once, then twice, and is now 2 nodes ahead of slow, on node 2.

@3-5
Now both move one node at a time, and the gap never changes. Slow on 1, fast on 3. Slow on 2, fast on 4. Slow on 3, fast on 5.

@6
Fast is on the tail. Because the gap is exactly 2, slow is sitting just before the 2nd node from the end, which is 4. That is the position deletion needs: the node before the target.

@7
Splice: slow's next skips over 4 and points at 5. Node 4 is unlinked in constant time, and no other node moves.

@8
The list is 1, 2, 3, 5. One pass, linear time, constant space. Return the dummy's next as the head; that is what lets "remove the first node" work without a special case. In an interview, mention that counting the length and walking again is also linear. The gap version reads fewer nodes twice, and it shows the offset-pointer idea interviewers are looking for.
