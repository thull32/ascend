@0
An app, a Bloom filter, and a disk behind it. The filter is just 16 bits, all zero, and 3 hash functions. It answers one question, have I seen this key, with either definitely not or probably yes. It can never say definitely yes, and it never forgets a key it was given.

@1-3
Add apple: its three hashes are 5, 6 and 7, so those bits are set. Banana hashes to 6, 15 and 8. Bit 6 is already set, and set bits simply stay set. Cherry sets 14, 3 and 0. Three keys have set 8 of the 16 bits, and the estimated false positive rate has climbed to about 8 percent.

@4-6
Query apple. Bits 5, 6 and 7 are all 1, so the answer is probably present. A key that was added always has all its bits set, so the filter never misses a key it holds. Only now does the app pay for the disk read, and apple is there.

@7-8
Query blue, a key that was never added. Its bits are 11, 2 and 5. Bit 5 happens to be set, by apple, but bit 11 is 0, and one zero is proof: if blue had ever been added, bit 11 would be 1. Definitely absent, and the disk read is skipped entirely. That is the whole point: most lookups for missing keys cost no input or output at all.

@9-10
Now beta, also never added. Its bits are 5, 0 and 15, and the added keys have set all three: apple set 5, cherry set 0, banana set 15. So the filter says probably yes, the app reads the disk, and finds nothing. A false positive. It costs a wasted read, never a wrong answer.

@11
Two caveats. You cannot delete: clearing apple's bit 6 would also erase part of banana's evidence and create a false negative. Counting variants or periodic rebuilds handle keys that come and go. And the false positive rate rises as the filter fills, so size it for the final number of keys.

@12
The trade is a few bits of memory per key for a definite no on most misses. At about 10 bits per key with around 7 hash functions, the false positive rate is under 1 percent. That is why log-structured stores like RocksDB and Cassandra keep a Bloom filter per file and check it before every read, so a lookup for a missing key touches no file at all.
