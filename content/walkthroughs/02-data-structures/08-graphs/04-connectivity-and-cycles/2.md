@0
Five vertices and six directed edges: A to B, B to C, and A to C, a small diamond; then A to D, D to E, and E back to A. In a directed graph, already visited does not mean cycle. You have to tell apart a vertex on the current path from one that is fully explored, and three colours do it. White is undiscovered. Grey is on the current path: the search is still inside it. Black is finished.

@1-3
Depth-first search enters A, then follows A's edge to B, then B's edge to C. All three are grey: they form the current path, A, B, C.

@4-5
C has no outgoing edges, so it is finished and turns black. B has nothing left either, and turns black too. The path shrinks back to A.

@6
A's next edge leads to C. C has been visited, but it is black: finished, and not on the current path. Two routes into the same vertex, A to B to C and A to C, are not a cycle. A check that only asks whether C was visited would report one here, and it would be wrong.

@7-8
A's last edge leads to D, which is white, so enter D, and from D enter E. The grey path is A, D, E.

@9
E's edge leads to A, and A is grey: still on the current path. That is a back edge, so there is a cycle, A to D to E and back to A, and the search stops there. A graph with a cycle has no topological order. The rule to remember: an edge to a grey vertex is a cycle, while an edge to a black vertex, one that is already finished, is harmless.
