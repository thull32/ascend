@0
Five vertices and six directed edges: A to B, B to C, A to C, then C to D, D to E, and E back to C. In a directed graph, already visited does not mean cycle. You have to tell apart a vertex on the current path from one that is fully explored, and three colours do it. White is undiscovered. Grey is on the current path: the search is still inside it. Black is finished.

@1-3
Depth-first search enters A, then follows A's edge to B, then B's edge to C. All three are grey: they form the current path, A, B, C.

@4-5
From C it goes on to D, and from D to E. The grey path is now five vertices long.

@6
E's edge leads to C, and C is grey: still on the current path. That is a back edge, so there is a cycle, C to D to E and back to C, and the search stops there. A graph with a cycle has no topological order. The rule to remember: an edge to a grey vertex is a cycle, while an edge to a black vertex, one that is already finished, is harmless.
