@0
Five vertices. A, B, C and D form a 4-cycle, and E hangs off D. A graph is bipartite if it can be coloured with two colours so that no edge joins two vertices of the same colour. Breadth-first search does it with one rule: every neighbour gets the opposite colour. If an edge ever joins two vertices that already share a colour, the graph is not bipartite, and that edge closes an odd cycle.

@1-2
Start at A with the first colour. Its neighbours B and D both get the opposite colour.

@3-4
B is dequeued, and its neighbour C gets the colour opposite to B, which is A's colour again. Then D's neighbour E gets the colour opposite to D. D's other neighbours, A and C, already have the opposite colour to D, so there is no conflict.

@5
Every edge joins two different colours, so the graph is bipartite: A, C and E on one side, B and D on the other. The 4-cycle coloured consistently, because walking round a cycle flips the colour once per edge, and an even cycle lands back where it started. Add an edge from A to C and you would close an odd cycle, and that edge would join two vertices of the same colour. The trap: run this from every uncoloured vertex, because a disconnected graph is bipartite only if every component is.
