@0
This is the lesson's example tree: 4 at the root, minus 3 on its left and 6 on its right. Under minus 3 hang two long arms: 8, then 7, then minus 1 on one side, and minus 5, then 9, then 10 on the other. The diameter is the longest path between any two nodes, counted in edges. Any path has some highest node, so each call does two jobs at once: it returns its subtree's height to its parent, and on the way it offers the path through itself as a candidate for a running best. Heights count edges, so a leaf has height 0 and an empty side minus one, and the path through a node is left height plus right height plus 2, one edge down into each side.

@1-5
A node cannot measure the path through itself until both children have reported their heights, so the calls run post-order. We enter 4, minus 3, 8, 7 and finally the leaf minus 1, and the call stack holds all five.

@6
Minus 1 is a leaf: minus one plus minus one plus 2 is a path of 0 edges, and the best stays 0. It returns height 0.

@7-8
Back at 7: 0 on the left, minus one on the right, so the path through 7 is 1 edge, a new best. It returns height 1. Node 8 does the same one level up: a path of 2 edges, best 2, height 2.

@9-12
Now the other arm. We enter minus 5, then 9, then the leaf 10, which returns height 0.

@13-14
Node 9 sees a path of 1 edge and returns height 1; minus 5 sees a path of 2 and returns height 2. Neither beats the best of 2, so it stays put.

@15
Here is the moment the whole pass exists for. At minus 3, both arms report height 2, so the path through it is 2 plus 2 plus 2: 6 edges, from minus 1 up through 7, 8, minus 3, and down through minus 5 and 9 to 10. That beats 2, so the best becomes 6. Minus 3 returns only one arm to its parent, height 3, because a path that continues upward can use one side, not both.

@16-17
The right child of the root, 6, is a leaf: path 0, height 0.

@18
At the root: 3 plus 0 plus 2 is a path of 5 edges, less than 6, so the best stays 6. The root's own candidate is not the answer, which is exactly why the best is updated at every node rather than read off the root. The root returns height 4, the height of the tree.

@19
The diameter is 6 edges, highlighted, found at minus 3. One pass, linear time. The version people write first calls a separate height function at every node, which on a chain of a hundred thousand nodes means about five billion visits. The fix is always the same: return the helper's value from the same pass.
