@0
The lesson's second trace: the values 5, 1, 1, 1, 1, and the maximum of every window of 2. Below them is a deque of indices, with each index's value shown. The rule to hold onto: the values in the deque decrease from front to back, so the front is always the maximum of the current window. This input is chosen because it needs both of the deque's eviction rules.

@1-2
Index 0, value 5, goes in at the back. Index 1, value 1, is smaller, so it joins behind it: 5, then 1.

@3
The first window, positions 0 and 1, is complete. Its maximum is the front: 5.

@4-5
Index 2 brings another 1. It equals the 1 at the back, so the older 1 is evicted from the back: the newer one is just as large and will stay in the window longer. Then index 2 is pushed. The deque holds index 0, value 5, and index 2, value 1.

@6
Now the second rule. The window is positions 1 to 2, and the front, index 0, is no longer in it. Nothing bigger than 5 ever arrived to push it out from the back; it simply got too old. So it is expired from the front.

@7
The window from 1 to 2 has maximum 1, the new front. Without the expiry step, the answer here, and for every window after it, would wrongly be 5.

@8-13
The rest repeats one pattern. Each new 1 evicts the equal 1 at the back, is pushed, and becomes the front, so windows 2 to 3 and 3 to 4 both report 1.

@14
The result is 5, 1, 1, 1. Each index entered the deque once and left at most once, from one end or the other, so the whole pass is linear, not window size times length. Both rules are needed: back pops remove values that a newer, larger or equal value has dominated, and the front pop removes the maximum when it ages out of the window. A solution with only back pops passes the first trace in the lesson and reports 5 forever on this one.
