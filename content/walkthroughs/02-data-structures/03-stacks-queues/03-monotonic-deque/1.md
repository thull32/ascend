@0
Eight values: 1, 3, minus 1, minus 3, 5, 3, 6 and 7, and we want the maximum of every window of 3. Below them is a deque of indices, with each index's value shown. The rule to hold onto: the values in the deque always decrease from front to back, so the front is always the maximum of the current window.

@1
Index 0, value 1, goes in at the back.

@2-3
Index 1 brings 3. The value at the back is 1, and 3 is at least as big, so 1 is evicted from the back. Any window that contains 1 from here on also contains this 3, so 1 can never be a window maximum again. Then index 1 is pushed.

@4-5
Index 2 brings minus 1. It is smaller than 3, so it simply joins the back: the deque is 3, then minus 1. The first window, positions 0 to 2, is now complete, and its maximum is read straight off the front: 3.

@6-7
Index 3 brings minus 3, smaller again, so the deque grows to 3, minus 1, minus 3, still decreasing. The window is now positions 1 to 3, and the front is still 3, so the maximum is 3. Notice that the 3 at index 1 is still inside this window, so it has not expired.

@8-10
Index 4 brings 5, and this is where the back does the work. Five beats minus 3: evict. Five beats minus 1: evict. Five beats 3: evict. Three candidates are gone in one arrival, and the deque is empty.

@11-12
Push index 4. The window is positions 2 to 4, and its maximum is the front, 5.

@13-14
Index 5 brings 3. It is smaller than 5, so it queues behind it: the deque is 5, then 3. Window 3 to 5, maximum 5.

@15-17
Index 6 brings 6. It evicts 3 from the back, then 5, and is pushed alone.

@18
Window 4 to 6, maximum 6.

@19-21
Index 7 brings 7, which evicts 6 and is pushed. The last window, 5 to 7, has maximum 7.

@22
The result is 3, 3, 5, 5, 6, 7. Each index entered the deque once and left at most once, so the whole pass is linear, not window size times length. One honest caveat: on this input, nothing ever expired from the front, because every old maximum was evicted from the back first. Both rules are needed in general. With 5 followed by a run of 1s, nothing bigger ever arrives, and 5 must leave from the front once it falls out of the window, or the answer would be 5 forever.
