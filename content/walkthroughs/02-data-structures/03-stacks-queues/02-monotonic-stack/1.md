@0
Eight daily temperatures: 73, 74, 75, 71, 69, 72, 76 and 73. For each one we want the next warmer value to its right. Below the array is a stack of indices, and one sentence is the whole algorithm: the values at the stacked indices are always strictly decreasing from bottom to top, and every index on the stack is still waiting for its answer.

@1
Index 0, value 73, has nothing to compare against, so it is pushed and starts waiting.

@2-3
Index 1 brings 74. The top of the stack holds 73, which is smaller, so 74 is its next greater element: pop index 0 and record 74 as its answer. The stack is empty, so push index 1.

@4-5
The same again. Seventy-five beats 74, so index 1 is popped with answer 75, and index 2 is pushed.

@6-7
Now the temperatures fall: 71, then 69. Neither is greater than the top, so nothing is resolved. Both are pushed, and the stack holds indices 2, 3 and 4, with values 75, 71 and 69. Still decreasing, and all three are waiting.

@8-9
Index 5 brings 72, and one new element answers two waiting ones. Seventy-two beats 69 on top: pop index 4, answer 72. The new top is 71, and 72 beats that too: pop index 3, answer 72. The next top is 75, which 72 does not beat, so the popping stops.

@10
Push index 5. The stack holds 75 and 72, decreasing again.

@11-12
Index 6 brings 76, the warmest yet. It pops index 5, answer 76, and then index 2, whose 75 has waited four days, answer 76. The stack is empty.

@13-14
Push index 6. Then index 7 brings 73, which is not greater than 76, so it is pushed on top, and the input ends.

@15
Indices 6 and 7 are still on the stack, so neither has a greater element to its right, and they get minus 1. Count the work: eight pushes and six pops for eight elements. Each index is pushed once and popped at most once, so the loop inside a loop costs linear time in total, not quadratic. Store indices rather than values, because the index is what gives you the distance: for daily temperatures, the days to wait.
