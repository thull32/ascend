@0
The text is a b a b a b c a, and the pattern is a b a b. Knuth-Morris-Pratt rests on one idea: when you have matched some characters, you have learned something about the text, so never throw it away by backing up. Phase 1 builds the failure table. Entry i is the length of the longest proper prefix of the pattern, up to position i, that is also a suffix of it: its longest border. Entry 0 is 0 by definition.

@1
At position 1 the pattern has b, which differs from the a at position 0, and there is no shorter border to fall back to. So entry 1 is 0.

@2-3
At position 2, a equals the pattern's first character, so the border grows to 1. At position 3, b equals the second character, so it grows to 2. The table is 0, 0, 1, 2. That final 2 says the full pattern a b a b ends with a b, which is also how it begins.

@4
Phase 2 scans the text once. The text index only moves forward, never back.

@5-8
The first four text characters match the pattern one by one, and that is a full match at position 0. Now the naive loop would back up to position 1 and start over. KMP reads the last table entry instead: 2. The a b it just matched is already the start of the next possible match, so it slides the pattern to 2 characters matched and carries on from the next text character.

@9-10
Text position 4 is a, matching pattern position 2, and position 5 is b, completing a second full match, at position 2. The two matches overlap, and neither cost a single re-read. Again the pattern slides back to 2 matched.

@11-12
Text position 6 is c, which does not match the pattern's a. With 2 characters matched, the table says fall back to a border of 0, and the text index stays put. The c does not match the pattern's first character either, and with nothing matched, the index moves forward by one.

@13
Position 7 is a, matching the start of the pattern, and the text runs out.

@14
Two matches, at positions 0 and 2, in eight steps over eight characters. The cost is the text length plus the pattern length, worst case, because the matched count rises by at most one per character and every fall-back lowers it. That guarantee is why KMP is the algorithm for streams and hostile input, and the same failure links power Aho-Corasick.
