@0
We start from an empty trie, and we are going to fill it with every suffix of banana. The idea that makes this useful is one sentence: every substring of a text is a prefix of some suffix. So once all the suffixes are in a trie, does the pattern occur in the text becomes does any suffix start with it, and the trie answers that with one step per character.

@1-7
The first suffix is the whole word, banana. The trie is empty, so every character creates a new node: b, a, n, a, n, a. The last one is marked terminal.

@8-13
The second suffix is anana. Nothing under the root starts with a yet, so it builds a second chain of five new nodes, ending in a terminal.

@14-18
Then nana: a third chain, n, a, n, a, all new, with a terminal at the end.

@19-22
Now the sharing starts. The suffix ana walks a, n, a down the anana branch, which already exists, so no node is created. The node at the end of a n a is simply marked terminal.

@23-27
Likewise na follows the first two nodes of the nana branch and marks its end terminal, and the last suffix, a, follows one edge from the root and marks that node. Six suffixes, and the last three cost no new nodes at all.

@28-31
Now a substring query: does nan occur in banana? Walk n, a, n from the root. The path exists, so the answer is yes. This is a prefix check, so no terminal flag is needed: nan is a prefix of the suffix nana, which is all it takes.

@32-35
Next, nab. The walk follows n and a, then finds no b under n a. It falls off the trie after 3 steps, so nab is not a substring of banana.

@36-39
Last, ana: a, n, a, and the path exists, so ana occurs. It is in fact a prefix of two suffixes, anana and ana, and that is how the trie sees a substring that occurs twice.

@40
Six keys in 16 nodes, and each query cost one step per pattern character, no matter how long the text. Here is the catch. A suffix trie can need a node for every distinct substring, roughly n squared over 2, which for a one megabyte text is on the order of 500 billion nodes. That is why the suffix tree compresses the chains, and why in practice you build a suffix array.
