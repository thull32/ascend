@0
The array is 0, 1, 0, 3, 12, and the job is to move every zero to the end while keeping the other values in their original order. Two pointers move in the same direction. The read pointer visits every element. The write pointer marks where the next non-zero value goes.

@1
Position 0 holds a zero. Skip it. The read pointer moves on, and the write pointer stays at 0.

@2
Position 1 holds 1, which is non-zero, so swap it with the slot at the write pointer. The array becomes 1, 0, 0, 3, 12, and the write pointer moves up to 1.

@3
Position 2 is another zero. Skip.

@4-5
Position 3 holds 3: swap it into position 1, and the array reads 1, 3, 0, 0, 12. Then 12 at position 4 swaps into position 2. Each swap carries a zero backwards into the gap the value left behind.

@6
The result is 1, 3, 12, 0, 0. One pass, linear time, in place. It is stable for free: the read pointer meets the kept values in order, and the write pointer places them in order. Swapping rather than overwriting is what keeps the zeros alive, so there is no second pass to fill the tail. The same loop removes duplicates, removes every copy of a value, or compacts a buffer.
