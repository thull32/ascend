@0
Eight values: 3, 1, 4, 1, 5, 9, 2, 6. Below them is an empty prefix array. Each prefix entry will hold the running total up to and including that position. Build it once, in one pass, and any range sum after that is a single subtraction.

@1-2
The first entry is just the first value, 3. The second is the previous total plus the next value: 3 plus 1, which is 4. That is the whole rule, one addition per element.

@3-8
The rest follows the same way. 4 plus 4 is 8. Plus 1 is 9. Plus 5 is 14. Plus 9 is 23. Plus 2 is 25. Plus 6 is 31. The last entry is the sum of the whole array.

@9
Now a query: the sum of positions 1 through 6. Take the running total at position 6, which is 25, and subtract the total just before the range starts, at position 0, which is 3. Everything before the range cancels, and 25 minus 3 is 22, which is 1, 4, 1, 5, 9 and 2 added up. One subtraction, constant time, however long the range. For q queries the total cost is n plus q instead of n times q. One caution: this picture uses a prefix array the same length as the input, so a range starting at position 0 would need a special case. The lesson's version adds a leading zero for the sum of nothing, which makes every query the same subtraction and removes most off-by-one bugs.
