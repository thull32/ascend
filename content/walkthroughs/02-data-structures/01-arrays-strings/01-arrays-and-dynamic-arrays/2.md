@0
Nine sorted values: 1, 1, 2, 3, 3, 3, 5, 7, 7. We want the duplicates gone without shifting anything and without a second array. Two pointers do it: a read pointer that visits every element, and a write pointer that marks where the next kept value goes. Because the array is sorted, the rule is simple: copy a value only when it differs from the last one kept.

@1
Position 0 holds 1. Nothing has been kept yet, so it is new, and it stays at position 0.

@2
Position 1 holds another 1, a duplicate of the last kept value. Skip it. The read pointer moves on; the write pointer stays at position 1, waiting for something new.

@3-4
Position 2 holds 2, which is new, so it is written at position 1. Then position 3 holds 3, also new, and it is written at position 2. The front of the array now reads 1, 2, 3.

@5-6
The next two 3s are duplicates of the kept 3. Both are skipped, and the write pointer holds at position 3.

@7-8
Position 6 holds 5: new, so it is written at position 3. Position 7 holds 7: new, written at position 4.

@9
The last 7 is a duplicate. Skip it.

@10
Done. The first five slots hold the unique values: 1, 2, 3, 5 and 7, and the length to report is 5. What sits after them is leftover and can be ignored. One pass, so linear time, and constant extra space. Nothing was ever shifted; values were only overwritten. This read and write pointer idea is the foundation of every in-place array technique.
