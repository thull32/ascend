@0
A cache stampede, also called a thundering herd or a dog-pile. One hot key lives in the cache, and the database behind it only ever sees the occasional miss for it. The danger is a short window: the moment between the key expiring and the first successful refill.

@1
The time to live runs out, and the key vanishes. Nothing else changes. Requests for it keep arriving exactly as before.

@2-4
Forty requests arrive in the same instant. Each one checks the cache first, as it should, and each one misses, because nobody has put the value back yet. Every one of them now decides, independently, to rebuild it.

@5
So a database sized for about one query a second on this key receives 40 copies of the same expensive query at once. Latency spikes, the connection pool drains, and unrelated queries start to stall behind them.

@6
Eventually all 40 return the same answer, and all 40 write the same value into the cache. Thirty-nine of those queries were pure waste, and cascading failures often start exactly here.

@7-8
The first fix is request coalescing, also called single-flight. The first request to miss takes a short lock on the key, with a set-if-not-exists, and the other 39 see the lock and wait briefly, or serve a stale copy if one exists.

@9-10
Only the lock holder queries the database. It refills the cache and releases the lock, and the waiters read the fresh value. One query instead of 40.

@11
Two more fixes. Keep serving the stale value while a single background job refreshes it, which is stale-while-revalidate, or let each request refresh slightly early with a probability that rises as expiry approaches. And add random jitter to time-to-live values, so that keys warmed together by one deploy never expire together.

@12
Each fix has a price. Single-flight adds a lock round trip and a short wait on every miss, and serving stale means readers briefly see an old value. Both are far cheaper than a database falling over under 40 times its load. A senior answer names all three families, and picks one for the case at hand.
