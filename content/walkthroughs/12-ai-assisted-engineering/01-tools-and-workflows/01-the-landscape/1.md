@0
Five boxes in a loop: the user's task, the model deciding, the harness running a tool, the observation it returns, and a final answer. The task: how many open pull requests are older than 7 days? The agent has two tools, one that returns today's date and one that lists pull requests, filtered by state and creation date. Hold onto the division of labour, because it is the whole lesson: the model only decides; the harness executes.

@1
Iteration 1. The harness sends the system prompt, the tool definitions and the task, about 340 tokens. The model has no clock, and older than 7 days needs today's date, so it emits a structured tool call to the date tool. It does not run anything itself.

@2
The harness, not the model, decides what runs. A read-only tool, so it runs. Tool results are the agent's only contact with reality, so this is where you validate arguments and sandbox side effects.

@3
The result, September the 26th, 2026, is appended to the transcript. From now on it is part of the context for every decision, so a verbose tool output is paid for again on every later iteration.

@4-6
Iteration 2. The whole transcript is resent, about 390 tokens now. Seven days before the 26th is the 19th, so the model asks for the open pull requests created before 19 September. The harness runs it, and the answer comes back already counted: 4, numbers 412, 418, 421 and 430.

@7
Iteration 3, about 480 tokens. The count is already in the last tool result, so the model answers without a tool call and the loop ends: 4 open pull requests are older than 7 days.

@8
Three model calls and two tool calls. The prompt grew from 340 to 390 to 480, and because the whole transcript is resent every time, the run processed about 1,210 input tokens in total; that total grows roughly with the square of the loop's length. That is why harnesses carry guards: an iteration cap, here 6, a token budget, timeouts on tools, and a human confirmation before anything irreversible. Swap these two tools for grep, edit file and run tests, and this is a coding agent.
