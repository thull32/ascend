@0
A fix loop, one frame per iteration. The task: make the rate-limiter tests pass. The agent has three tools: read a file, edit a file, and run the tests. Watch two numbers on every frame: the input tokens on this call, which is the whole transcript, and the running total across all calls, which is what you pay for.

@1
Iteration 1. The harness sends the system prompt, the tool definitions, the memory file and the task, about 14,300 tokens. The agent reads the code under test, and about 3,000 tokens of it are appended.

@2
Iteration 2, 18,500 tokens: everything before, plus the file and the model's own output. The agent runs the test file. One test fails, the 11th request was allowed, and about 3,500 tokens of test output join the transcript.

@3
Iteration 3, 23,200 tokens, and 56,000 across the three calls so far. The agent changes the window check; the diff is appended.

@4
Iteration 4. It runs the tests again. The same test fails, and another 3,500 tokens of output go in. The total passes 81,000.

@5
Iteration 5, 29,700 tokens. A different change to the same file.

@6
Iteration 6, 31,500 tokens, and 142,200 across all six calls. The third test run fails the same way. Every failed attempt and every test log is still in the transcript, resent on this call and on every call after it.

@7
This is the moment the caption is about. The harness would carry on until its cap of 25 iterations, each one resending everything above. A person can stop sooner: three failures on the same test is the signal to write down what was ruled out and restart in a fresh session.

@8
Six calls, about 142,200 input tokens, although the last call sent only 31,500: the transcript is resent every time, so the total grows roughly with the square of the loop's length, and the later iterations are also the least focused. Iteration 6 alone carried both earlier attempts and their test logs. A reset with a short handoff note starts again near 14,300. Iteration caps and budgets are part of the harness for a reason; your equivalent is noticing the third failed attempt.
