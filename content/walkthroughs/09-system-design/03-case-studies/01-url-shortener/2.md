@0
Three boxes: an app server, Redis, and Postgres. On the redirect path, the app server is the redirect service and the database is the link store. The rule of cache-aside is that the application owns the logic: it reads the cache first, falls back to the database on a miss, and writes the result back itself. The cache never talks to the database.

@1-2
The app asks the cache for a key, here user 42. Miss: nothing has been loaded for it yet, because the cache is cold or the entry expired.

@3-4
So the app falls through to the database, the source of truth, at about 5 milliseconds, and gets the row back, version 1.

@5
The app writes it into the cache with a time to live of 300 seconds. Only keys that are actually read get cached, so memory goes to hot data. The shortener's Redis tier does the same with a 24 hour time to live plus jitter, sized for the links of the last 30 days and an evergreen tail, assumed to take over 90 percent of clicks.

@6
The second read is a hit, served in about half a millisecond without touching the database. That is the shortener's common case: in the lesson's design, roughly 95 percent of redirects end here or earlier.

@7-8
Now a write. The app updates the database first, to version 2, and then deletes the cache entry rather than writing version 2 into it. A delete is idempotent and cannot race with another writer's set; the next read reloads the fresh row.

@9
And the next read does exactly that: miss, database, set version 2. Every write costs one extra miss on the next read.

@10
Here is the classic race. Reader A misses and reads version 1 from the database. Writer B updates to version 2 and deletes the key. Then A's late set writes version 1 back, and the cache serves a stale value until the time to live runs out.

@11
The trade-off: simple and resilient, because a cache outage just means more database reads, but cache and database can briefly disagree. This is where the shortener gets lucky. Links are immutable, so the only invalidations are disable and expiry. There are almost no writes to race with, which is what makes a 95 percent hit rate cheap to hold.
