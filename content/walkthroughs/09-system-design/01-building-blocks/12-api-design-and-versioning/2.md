@0
A client, a rate limiter, and the API behind it. The limiter keeps a bucket for this API key: at most 5 tokens, refilled at 1 token a second. Every request takes one token, and a request that finds the bucket empty is rejected. Two numbers carry the whole contract: capacity is the burst you permit, and the refill rate is the rate you sustain.

@1-5
At time zero the client fires a burst. Requests 1 to 5 each take a token and go through: 4 left, 3, 2, 1, and then none. The burst was allowed, because the bucket was full.

@6-7
Requests 6 and 7 arrive in the same instant and find the bucket empty. Each gets a 429, Too Many Requests, with a Retry-After hint. The client pays for the overload, not the API.

@8
Request 8 comes at 2 seconds. Two tokens have refilled since time zero, so it takes one and goes through, leaving 1.

@9-11
At 3 seconds another token has arrived, so there are 2 again. Request 9 takes one, request 10 takes the last, and request 11, in the same second, gets a 429. A client that keeps pushing is held to the refill rate, about one request a second.

@12
Request 12 waits until 9 seconds. Six seconds have passed, but the bucket caps at 5, so it holds 5, takes one, and leaves 4. The tally: 9 accepted, 3 rejected. A client that read its remaining-quota header and paced itself would never have seen a 429 at all.

@13
Sizing the bucket is the judgment call. Too large a capacity lets a client dump a full bucket, 5 requests, on the API in one instant, and everything downstream must absorb that burst. Too small rejects legitimate bursts, such as a page that fires several API calls at once.

@14
That is why most API gateways implement a token bucket: it allows bursts up to capacity, enforces an average rate, and needs only two numbers per client, the token count and the last refill time. Limit by API key, not by IP address, because many customers share one NAT address and one customer uses many. And keep it distinct from load shedding: a 429 says wait exactly Retry-After, while a 503 from an overloaded server says back off with jitter.
