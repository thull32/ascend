@0
The maximum subarray sum of minus 2, 1, minus 3, 4, minus 1, 2, 1, minus 5 and 4. Cell i holds the best sum of a subarray that ends exactly at position i. That subarray either extends the best one ending just before, or starts fresh at i. Extending only helps if the previous best is positive, so each cell is its own value plus the previous cell, or plus nothing if the previous cell is not positive.

@1
Base case: the only subarray ending at position 0 is minus 2 itself, so cell 0 is minus 2.

@2
Position 1 holds 1. The run before it is minus 2, which would only drag it down, so start fresh: cell 1 is 1. Best so far, 1.

@3
Position 2 holds minus 3. The run before it is 1, positive, so extend: minus 3 plus 1 is minus 2. The best so far stays 1.

@4
Position 3 holds 4. The run before it is minus 2, so drop it and restart: cell 3 is 4, the new best.

@5-7
Now the run is positive, so it keeps extending. Minus 1 brings it to 3, 2 brings it to 5, and 1 brings it to 6. The best so far climbs to 6.

@8-9
Minus 5 drops the run to 1, but 1 is still positive, so it is kept. The final 4 extends it to 5. A positive run, however small, is worth carrying. The best so far stays 6.

@10
The maximum subarray sum is 6, from position 3 to position 6: 4, minus 1, 2 and 1. The answer is the maximum cell, not the last one, which is only 5. Each cell reads only the one before it, so a single variable replaces the row: that is Kadane's algorithm, linear time and constant space, and it is this DP with a rolling variable. The trap is the all-negative array: start the answer at the first element, not at 0, or you return a sum no subarray has.
