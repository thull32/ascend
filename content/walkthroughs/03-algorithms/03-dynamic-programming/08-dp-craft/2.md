@0
Can the string cats and dog, written with no spaces, be split back into dictionary words? The dictionary is cat, cats, and, sand and dog. There is no count and no minimum here, but there is a prefix state, and that makes it DP. Cell i is true when the first i characters can be segmented: some dictionary word ends exactly at position i, and the prefix before that word is itself segmentable.

@1
Base case: cell 0 is true. The empty prefix is trivially segmentable, and it is what the first word builds on.

@2-3
Cells 1 and 2, the first one and two letters: no word ends there, so both are false.

@4
Cell 3: cat ends here, and the prefix before it is empty, cell 0, which is true. So cell 3 is true.

@5
Cell 4: cats ends here, also on top of the empty prefix. True.

@6-7
Cells 5 and 6: no word ends at either, so both are false, even though cell 4 before them is true.

@8
Cell 7: the word and ends here, and the prefix before it is cats, cell 4, which is true. So the prefix cats and, without its space, is segmentable.

@9-10
Cells 8 and 9: no word ends there. False.

@11
The answer cell, 10, the whole string. Dog ends here, and the prefix before it is cell 7, true. So cell 10 is true.

@12
Yes: cats, and, dog. Following the recorded split points back from 10, to 7, to 4, to 0, reconstructs the words. The cost is the length of the string times the number of words times the word length, if each cell only tries the positions where a dictionary word could start. The lesson of this one is recognition: a yes or no question over prefixes is still DP, and the table is just a row of booleans.
