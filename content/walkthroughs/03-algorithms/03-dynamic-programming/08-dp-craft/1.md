@0
The table holds lengths, and the interviewer wants the subsequence itself. This is the longest common subsequence of A, G, G, T, A, B down the rows and G, X, T, X, A, Y, B across the columns. First the fill, quickly, because the walk back only makes sense on a finished table. A match takes the diagonal cell plus 1; a mismatch takes the larger of the cell above and the cell to the left.

@1
Base cases: row 0 and column 0 are empty prefixes, all zeros.

@2-5
Row A against G, X, T and X: no matches, so the row stays at 0.

@6
A against A, column 5: the first match. The diagonal is 0, so this cell is 1.

@7-8
The 1 carries to the end of the row, against Y and B.

@9
The first G row. G against G in column 1 is a match: 0 plus 1 is 1.

@10-15
Nothing else in the row matches, so every cell takes its larger neighbour and the row is 1 all the way across.

@16-22
The second G row repeats the first. G against G matches again, but its diagonal is still 0, so it is only 1, and the row stays 1. Two G's in one string cannot both pair with the single G in the other.

@23-24
The T row starts at 1 and 1, carried down from above.

@25
T against T in column 3: a match. The diagonal holds 1, so this cell is 2: G then T.

@26-29
The 2 carries to the end of the T row.

@30-33
The A row: 1, 1, then 2 and 2, carried from the T row above.

@34
A against A in column 5: a match on top of a diagonal 2, so 3: G, T, A.

@35-36
The 3 carries across the rest of the A row.

@37-42
The B row climbs the same way, 1, 1, 2, 2, 3, 3, without a match.

@43
The answer cell: B against B, a match on top of a diagonal 3. The LCS has length 4.

@44
Now the walk back, which is highlighted, and it is the fill run in reverse. At B against B, a match: emit B and step diagonally. At A against Y, a mismatch: the left neighbour holds 3 and the cell above holds 2, so step left. A against A matches: emit A, step diagonally. T against X: left is 2, above is 1, step left. T against T: emit T, diagonal. Then G against X, where above and left are both 1, a tie. The tie-break goes up, skipping the second G of the first string. G against X once more: left is 1, above is 0, step left. And G against G matches: emit G, and the walk reaches column 0. Read backwards, the emitted characters spell G, T, A, B. That tie is where the choice of subsequence is made: going left instead would also give a length-4 answer. If the problem wants a specific one, the tie-break has to be designed. The walk needs the full table in memory, which is why rolling rows and reconstruction do not mix without Hirschberg's divide and conquer.
