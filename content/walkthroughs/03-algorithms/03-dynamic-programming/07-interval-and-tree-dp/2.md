@0
This is the house-robber tree from the lesson: 3 at the root, 4 and 5 below it, leaves 1 and 3 under the 4, and a single leaf 1 under the 5. Now we compute its diameter, the longest path between any two nodes, counted in edges. In tree DP the table is the recursion's return values. Each call returns its subtree's height, the number of nodes on its longest downward path, so an empty side counts 0 and a leaf 1. On the way, it checks the longest path that bends through it, left height plus right height, against a global best.

@1-3
The recursion enters the root, then 4, then the leaf 1 beneath it. No node can do anything yet, because it needs the heights of both children first. That is post-order: children finish before their parent reads them.

@4
The leaf 1 has two empty sides, so the path through it is 0 edges, and the best stays 0. It returns height 1.

@5-6
The other leaf under 4, the 3, does the same: path 0, height 1.

@7
Now 4 has both answers, and this is the combine step. Its left reports height 1 and its right height 1, so the longest path bending through 4 is 1 plus 1, two edges, from one leaf up to 4 and down to the other. That beats the best, which becomes 2. But 4 returns only one arm to its parent: height 2.

@8-10
The root's right side next. Enter 5, then its leaf 1, which returns height 1.

@11
Node 5 has an empty left and a right height of 1, so the path through it is 1 edge, and the best stays 2. It returns height 2.

@12
Back at the root, both children have reported height 2. The path through the root is 2 plus 2, four edges: leaf 1, then 4, the root, 5, and the other leaf 1. That beats 2, so the best becomes 4, and the root returns height 3.

@13
The diameter is 4 edges, highlighted. Every node combined two numbers its children had already computed, and no node was visited twice, so one post-order pass is linear. The naive version, which recomputes the height at every node, is quadratic on a chain. The same shape solves maximum path sum and house robber itself: return a small tuple from each child, combine at the parent.
