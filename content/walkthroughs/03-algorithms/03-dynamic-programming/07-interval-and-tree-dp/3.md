@0
Three items, 3, 5 and 6, and every subset of them is a 3-bit number called a mask. Bit i set means item i is included, with bit 0 in the rightmost column. Counting the masks from 0 up to 7 lists all 8 subsets.

@1
Mask 0, all bits clear: the empty subset.

@2-3
Masks 1 and 2 have a single bit each. Mask 1, bit 0, is the subset holding 3. Mask 2, bit 1, is the subset holding 5.

@4
Mask 3 has bits 0 and 1: the subset 3 and 5. Notice that both of its smaller subsets, masks 1 and 2, were visited before it.

@5-7
Mask 4 is 6 alone. Mask 5 is 3 and 6. Mask 6 is 5 and 6.

@8
Mask 7, every bit set: the full set.

@9
All 8 subsets, in time proportional to 2 to the n. The order is the point. Removing a bit always makes a number smaller, so every proper subset of a mask comes before it, and plain increasing order is a valid fill order for any DP over subsets. In the assignment problem, bit w set means worker w is already taken, and a mask's value depends only on masks with one bit fewer. The catch is the size: 2 to the n states is about a million at n equal to 20, which is roughly where bitmask DP stops being feasible.
