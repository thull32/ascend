@0
This table is about the order, not the problem. The string is A, B, A, C, A, B, and cell i, j says whether the substring from i to j is a palindrome: its ends must match, and the interval strictly inside must already be known to be a palindrome. Every interval DP has this shape. A cell depends only on shorter intervals inside it, so the table fills diagonal by diagonal, by increasing length, never row by row.

@1
Length 1: every single character is a palindrome. The main diagonal is all true, six palindromes so far.

@2-6
Length 2, the next diagonal. No two neighbouring characters are equal, A B, B A, A C, C A and A B, so the whole diagonal is false.

@7
Length 3 begins: A, B, A. The ends match, and the inside, B, sits on the length-1 diagonal, already true. So it is a palindrome.

@8
B, A, C: the ends differ, false without looking inside.

@9
A, C, A: the ends match and the inside, C, is true. Another palindrome.

@10
C, A, B: the ends differ. False.

@11-13
Length 4: all three substrings have mismatched ends. The whole diagonal is false.

@14
Length 5 shows why the order matters. A, B, A, C, A has matching ends, both A, so the answer depends on the inside, B, A, C. That cell is on the length-3 diagonal, already filled, and it is false. So this one is false too.

@15
B, A, C, A, B: the ends match, both B, and the inside is A, C, A, which the length-3 diagonal marked true. So this one is a palindrome.

@16
Length 6, the whole string: it starts with A and ends with B. False.

@17
Nine palindromic substrings in all, and the longest is B, A, C, A, B. Only the upper triangle is used: quadratic time and space. The same diagonal sweep is the fill order for matrix chain multiplication and burst balloons. In matrix chain each cell also tries every split point, which costs linear work per cell and makes the whole table cubic. Whatever the problem, row by row would read an interval's inside from a later row, before it exists.
