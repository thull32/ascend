@0
Coin change is the unbounded knapsack in disguise. The coins, 1, 3 and 4, are items whose weight is their face value; the amount, 6, is the capacity; and instead of maximising value you minimise the number of coins. Each coin may be used any number of times. The loop is the unbounded knapsack's, item by item: for each coin c, sweep the amounts upward from c, and let cell a take 1 plus cell a minus c whenever that is fewer coins.

@1
Base case: cell 0 is 0, because no coins make zero. Nothing else can be made yet, so every other cell starts at infinity.

@2-7
First the 1 coin, swept upward. Cell 1 reads cell 0: one coin. Cell 2 reads cell 1, which was improved by this same coin a moment ago, so cell 2 is two coins of 1. Look at what that read means: the cell below already contains a 1 coin, and we add another. That is the upward sweep reusing an item, and it is exactly what unbounded means. The sweep continues to 3, 4, 5 and 6 ones.

@8-10
Now the 3 coin, from amount 3 upward. Cell 3 reads cell 0 and drops from 3 coins to 1. Cell 4 reads cell 1: a 3 and a 1, 2 coins instead of 4. Cell 5 reads cell 2: 3 coins instead of 5.

@11
Cell 6 reads cell 3, which this same pass has just set to a single 3 coin. So 6 becomes 2 coins: 3 plus 3. The coin repeats because the cell it reads is already updated for the same coin, which is the whole point of sweeping upward.

@12-14
Last, the 4 coin. Cell 4 drops to 1, a single 4. Cell 5 drops to 2, a 4 and a 1. Cell 6 tries a 4 on top of cell 2, which is 3 coins, no better than the 2 it already has, so it stays.

@15
Two coins: 3 plus 3, not the greedy 4 plus 1 plus 1. This is the one rule worth remembering from the knapsack family. Every read lands on a smaller amount that may already contain the same coin, so coins repeat: unlimited copies. In the one-row 0/1 knapsack the sweep runs downward, so each read sees the row from before the current item, and each item is used at most once. Same three lines of code, opposite direction, and the wrong direction gives silently wrong answers that small tests often miss.
