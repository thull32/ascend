@0
A bag that holds 7 kilograms, and four items: 1 kilogram worth 1, 3 kilograms worth 4, 4 kilograms worth 5, and 5 kilograms worth 7. Row i uses the first i items, column c is the capacity, and each cell holds the best value that fits. The recurrence is one decision about the newest item. Skip it, and the answer is the cell directly above. Take it, and you get its value plus the best the previous row could do with the capacity that is left. The take always reads the previous row, and that is what stops an item being used twice.

@1
Base case: row 0 has no items, so the best value is 0 at every capacity.

@2
Row 1 adds the 1 kilogram item. At capacity 0 it does not fit, so the cell copies the 0 above it.

@3-9
At capacity 1 it fits: its value 1 plus the 0 from the row above beats skipping. The same happens at every capacity up to 7, so the whole row reads 1. One item, taken once, however much room there is.

@10-12
Row 2 adds the 3 kilogram item, worth 4. At capacities 0, 1 and 2 it does not fit, so those cells copy the row above: 0, 1, 1.

@13
At capacity 3 it fits exactly. Taking it gives 4 plus the cell above at capacity 0, which is 0, so 4, beating the 1 from skipping.

@14
At capacity 4, taking it gives 4 plus the row above at capacity 1, which is 1: both items, for 5.

@15-17
Capacities 5, 6 and 7 can do no better with two items, so they all hold 5.

@18-21
Row 3 adds the 4 kilogram item, worth 5. Capacities 0 to 3 are too small, so they copy the row above.

@22
At capacity 4 the item fits, but taking it alone is worth 5, exactly what skipping already gives. A tie goes to skip: 5.

@23-24
At capacities 5 and 6, taking it adds 5 to the 1 the row above has left at capacity 1 or 2: 6.

@25
At capacity 7, taking it reads the row above at capacity 3, which holds 4: the 3 kilogram item. Five plus 4 is 9, far better than the 5 from skipping.

@26-30
Row 4 adds the 5 kilogram item, worth 7. Capacities 0 to 4 cannot hold it, so they copy the row above.

@31-32
At capacity 5, taking it alone gives 7, beating 6. At capacity 6, taking it plus the 1 kilogram item gives 8.

@33
The answer cell, capacity 7. Taking the 5 kilogram item leaves 2 kilograms, worth 1, for 8. Skipping keeps the 9 from the row above. Skip wins: 9.

@34
The best value is 9, and the walk back is highlighted. Start at the answer cell and walk up. If a cell equals the one above, its item was not taken. If it differs, the item was taken, so subtract its weight from the capacity and continue. Row 4 equals the row above, so the 5 kilogram item is out. Row 3 differs, so the 4 kilogram item is in and 3 kilograms remain. Row 2 at capacity 3 differs, so the 3 kilogram item is in. That is 7 kilograms for 9, which greedy by value or by value per kilogram both miss. The time is items times capacity, which is pseudo-polynomial: it depends on the capacity's value, not on how many digits it takes to write.
