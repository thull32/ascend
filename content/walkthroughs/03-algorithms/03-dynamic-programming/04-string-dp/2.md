@0
Edit distance from horse to ros: the fewest single-character insertions, deletions or substitutions. Rows are prefixes of horse, columns prefixes of ros. Each cell asks about the last characters. If they match, no edit is needed: copy the diagonal. Otherwise the last edit was one of three, each costing 1: substitute, reading the diagonal; delete from horse, reading the cell above; or insert from ros, reading the cell to the left. Take the cheapest.

@1
The border is the first thing to get right, and it is not zeros. Turning a prefix of length i into the empty string takes i deletions, and building a prefix of length j from nothing takes j insertions. So the edges count up 0, 1, 2, 3 and so on.

@2
H against R: different. Substitute reads the diagonal, 0; delete and insert both read 1. The cheapest is substitute: 1 plus 0 is 1. Change H into R.

@3-4
The rest of row H, against O and then S, gives 2 and 3: one letter of horse has to become two and then three letters of ros, and each extra letter costs one more edit.

@5
Row O starts with O against R, a mismatch: 1 plus the cheapest of 1, 1 and 2, which is 2.

@6
O against O: a match, so no edit. Copy the diagonal, which is 1. Turning H, O into R, O takes one substitution.

@7
O against S: the cheapest is to insert S, reading the cell to the left, 1. So 2.

@8
Row R starts with R against R: another match. Copy the diagonal, 2: turning H, O, R into R means deleting H and O.

@9-10
R against O: deleting R is cheapest, 1 plus 1 is 2. Then R against S: substituting is cheapest, 1 plus 1, also 2.

@11-13
Row S: against R, delete S, 3; against O, 3; then S against S matches and copies the diagonal, 2.

@14-15
Row E begins with two mismatches, against R and against O, each 4.

@16
The answer cell: E against S. Substitute would cost 1 plus 3, delete 1 plus 2, insert 1 plus 4. Delete wins: the distance is 3.

@17
Three edits, and the walk back from the answer cell is highlighted. At each cell it asks which neighbour explains the value, and that recovers the edits: substitute H with R, delete R, delete E, so horse becomes rorse, then rose, then ros. A diagonal step on a match is free. Note the shape: this table reads the same three neighbours as LCS; only the border and the combine differ. The time is the product of the two lengths, and two rows are enough memory if you do not need the edit script.
