@0
The string is B, A, B, A, D, and cell i, j answers one yes or no question: is the substring from position i to position j a palindrome? It is exactly when its two end characters match and the part strictly inside is itself a palindrome. That inside is a shorter interval, so the table fills by increasing length, not row by row.

@1
Length 1: every single character is a palindrome, so the whole main diagonal is true. Five palindromes so far.

@2-5
Length 2: two characters are a palindrome only if they are equal. B A, A B, B A and A D all differ, so the whole length-2 diagonal is false.

@6
Length 3, starting at 0: B, A, B. The ends match, both B, and the inside, a single A, was marked true on the first diagonal. So it is a palindrome.

@7
A, B, A: the ends match, both A, and the inside B is a palindrome. True again.

@8
B, A, D: the ends, B and D, differ, so it is false without looking inside.

@9-11
Length 4 and length 5 all fail at the ends. B A B A starts with B and ends with A; A B A D starts with A and ends with D; and the whole string starts with B and ends with D. All false.

@12
Seven palindromic substrings: the five single characters, plus B A B and A B A. The longest is B A B, found at row 0, column 2; A B A is equally long. Only the upper triangle is used, so time and space are both quadratic. For this particular question, expanding around each centre is also quadratic time with constant space, and is usually the answer to write; the table earns its keep when many overlapping palindrome questions are asked, or for the subsequence version.
