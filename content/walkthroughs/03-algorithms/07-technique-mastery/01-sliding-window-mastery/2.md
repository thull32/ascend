@0
Eight values: 2, 1, 5, 1, 3, 2, 7, 1, and a window of exactly three. We want the three neighbours with the largest sum. Build the first window once: 2 plus 1 plus 5 is 8.

@1
Now slide. A fixed window needs no shrink condition: each step admits one element on the right and evicts one on the left. Add the 1 at position 3, remove the 2 at position 0, and the sum is 7. The best so far is still 8.

@2
Add 3, remove 1: the sum is 9, a new best.

@3
Add 2, remove 5: the sum falls to 6.

@4
Add 7, remove 1: the sum jumps to 12, the new best, for the window 3, 2 and 7.

@5
Add the final 1, remove 3: the sum is 10. That was the last slide.

@6
The maximum sum is 12, for the window starting at position 4. One pass, one addition and one subtraction per step, so order of n, instead of re-adding all k elements for every window. Eight elements, eight updates, whatever the size of the window.
