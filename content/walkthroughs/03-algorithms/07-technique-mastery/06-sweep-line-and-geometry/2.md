@0
Eight points, sorted by x and then y and numbered 0 to 7: the corners of a four by four square, plus four points inside or on its edges. The monotone chain builds the lower edge of the convex hull with a stack. Before pushing each point, pop the top while the last two stack points and the new point fail to make a strict left turn. The cross product's sign decides, and with integer coordinates that test is exact.

@1-2
Point 0, the corner at 0, 0, is pushed. Then point 1, at 0, 4.

@3-4
Point 2 is at 1, 3. From point 0 through point 1 to point 2 is a right turn, a cross product of minus 4, so point 1 cannot be a corner of the lower chain. It is popped, and point 2 is pushed.

@5
Point 3 is at 2, 0. Again a right turn, minus 6, so point 2 is popped, leaving point 0 on top.

@6-7
Point 3 is pushed. Then point 4, at 2, 2: from 0, 0 through 2, 0 to 2, 2 is a left turn, a cross product of plus 4, so it is pushed with nothing popped. Three points on the stack.

@8-9
Point 5, at 3, 1, makes a right turn after point 4, so point 4 is popped, and point 5 is pushed.

@10-11
Point 6 is the corner at 4, 0. It turns right after point 5, so point 5 is popped. Then the test runs again, and this is the case to remember: 0, 0, then 2, 0, then 4, 0 are collinear, a cross product of exactly 0. Not a strict left turn, so point 3 is popped too. A point lying on an edge is not a corner.

@12-13
Point 6 is pushed. Then point 7, the corner at 4, 4, turns left, plus 16, and is pushed.

@14
The lower chain is 0, 0, then 4, 0, then 4, 4. Every operation touched only the top of the stack, and each point was pushed once and popped at most once, so the pass is linear after the sort. Run the same loop over the points in reverse for the upper chain, join the two, and you have the hull: the four corners of the square. Change the test to pop only on a strict right turn, and collinear edge points like 2, 0 would stay on the hull, which some problems want and most do not.
