@0
The nodes here are labelled fib, the Fibonacci function, and that is no accident: ways of n is ways of n minus 1 plus ways of n minus 2, exactly the Fibonacci recurrence, so the call tree is the same tree, call for call. Each node makes two calls. Your job while it runs is to count how many times the node for 2 appears.

@1-5
The calls go straight down the left edge. 6 needs 5 and 4, so it calls 5 first and waits. 5 calls 4, 4 calls 3, 3 calls 2, and 2 calls 1. Six frames are now waiting on each other.

@6-9
1 is a base case and returns 1 immediately. Back in the node for 2, the second call goes to 0, another base case, which returns 0. So the node for 2 returns 1 plus 0, which is 1. That is the first time 2 has been solved.

@10-12
Back in the node for 3, its second call goes to 1, a base case. 3 returns 1 plus 1, which is 2.

@13-19
Back in the node for 4, the second call goes to 2. This is the second call for 2. Its value, 1, is already known, but naive recursion has no memory, so the whole subtree runs again: a call to 1, a call to 0, add them. Then 4 returns 2 plus 1, which is 3.

@20-30
Back in 5, its second call goes to 3, the second time 3 has been asked. And inside it, 2 is called for the third time. The same small subtrees, computed from scratch, again. 3 returns 2, and 5 returns 3 plus 2, which is 5.

@31-48
Back at the root, its second call goes to 4, for the second time. That one call drags in the whole left-hand work again: 3 for the third time, 2 for the fourth time, and then, back in 4, 2 for the fifth time. Every one of those subtrees returns the same numbers as before. 4 returns 3.

@49
The root returns 5 plus 3, which is 8. Count them: the node for 2 appeared five times, the node for 3 three times, the node for 4 twice.

@50
25 calls, but only 7 distinct arguments, 0 through 6. The live stack never went past 6 frames; the waste is all in time. The number of calls grows like 1.6 to the n, so at n equal to 40 it is about 330 million. The function is pure, so the fix is to write each answer down the first time: memoise those 7 results, and the cost becomes linear.
