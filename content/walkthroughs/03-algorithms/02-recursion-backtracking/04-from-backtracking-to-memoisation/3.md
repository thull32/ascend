@0
Can the string apple pen apple, written with no spaces, be cut into dictionary words, when the dictionary is apple and pen? The table here has one cell per position. Cell i is true when some dictionary word ends exactly at position i and the part before that word can itself be split. The point is that the whole state is one number: once you know the position, how you got there does not matter.

@1
Cell 0 is the base case, true: the empty prefix splits trivially, into nothing.

@2-5
Positions 1 to 4 end after the first one, two, three and four letters of apple. No dictionary word ends at any of them, so all four cells are false.

@6
At position 5, apple ends, and the part before it is empty, which cell 0 says is fine. So cell 5 is true.

@7-8
At positions 6 and 7 no word ends, so both are false.

@9
At position 8, pen ends. The part before it is apple, and cell 5 already says apple splits. So cell 8 is true. Notice that nothing was re-explored: one lookup answered the whole question about the prefix.

@10-13
Positions 9 to 12 end in fragments of the last apple. No word ends there, so all four are false.

@14
At position 13, the end of the string, apple ends, and the part before it, apple pen, is cell 8: true. So cell 13 is true.

@15
The string splits as apple, pen, apple, recovered by following the split points back to 0. Thirteen states, each decided once. The lesson's code asks the same question from the other end, about the rest of the string starting at i, but either way the state is one index. Without that table, a string of 24 copies of the letter a followed by one b, with a dictionary of runs of one to four a's, takes over 8 million calls; with it, 25 states.
