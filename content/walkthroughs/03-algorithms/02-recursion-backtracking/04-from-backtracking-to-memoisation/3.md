@0
Can the string apple pen apple, written with no spaces, be cut into dictionary words, when the dictionary is apple and pen? This is the lesson's can of i: can the rest of the string, starting at position i, be split into words? The table has one cell per position, and the point is that the whole state is that one number. However the recursion got to position i, the answer for the rest is the same, so it only ever needs deciding once.

@1
Start at the end. Cell 13, just past the last letter, is the base case, true: an empty rest splits trivially, into nothing. Every other cell reads only cells to its right, so the table fills from right to left.

@2-5
Positions 12 down to 9 start the fragments e, l e, p l e and p p l e. No dictionary word starts at any of them, so all four cells are false.

@6
At position 8, apple starts, and right after it is position 13, the end, which is true. So cell 8 is true: the final apple splits.

@7-8
Positions 7 and 6 start n apple and e n apple. No word starts there, so both are false.

@9
At position 5, pen starts. After it comes position 8, and cell 8 already says the rest splits. So cell 5 is true. Notice that nothing was re-explored: one lookup answered the whole question about the rest of the string.

@10-13
Positions 4 down to 1 start in the middle of the first apple. No word starts there, so all four are false.

@14
At position 0, apple starts, and after it is position 5: true. So cell 0 is true, and that is the answer to the whole question.

@15
Following the recorded words forward from 0 gives apple, pen, apple. Thirteen states plus the base case, each decided once. The recursive code reaches the same cells on demand, from can of 0, and the memo is what stops it deciding any of them twice. Without it, a string of 24 copies of the letter a followed by one b, with a dictionary of runs of one to four a's, takes over 8 million calls; with it, 25 states.
