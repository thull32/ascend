@0
Nine values, each 0, 1 or 2. Read 0 as below the pivot, 1 as equal to it, and 2 as above it. We want all the 0s first, then the 1s, then the 2s, in one pass. Three pointers split the array into four zones. Everything before low is a 0, everything from low up to mid is a 1, everything after high is a 2, and the zone from mid to high is still unexamined. Each step looks at the element under mid and shrinks the unknown zone by one.

@1
Mid starts at position 0, which holds a 1. A 1 is already in the right zone, so mid simply moves on.

@2
Position 1 holds a 2. It swaps with the element under high, at the far end, and high moves left. Mid does not move, because the value that just swapped in has not been examined yet. Here it is a 0.

@3-4
And that 0 swaps down to low, and both low and mid advance. The next element is another 0, and it does the same. The array now begins 0, 0, 1.

@5
Mid finds a 2 at position 3. It swaps with the 1 under high, at position 7, and high moves left again. The last three positions are now 2s.

@6-7
The swapped-in 1 stays put, and so does the 1 after it: mid just advances twice.

@8
Mid finds a 0 at position 5. It swaps with the first 1, at position 2, so the 0s grow to three and the band of 1s shifts right by one.

@9
The last unknown element, at position 6, is a 2, and swapping it with itself closes the unknown zone.

@10
Done in a single pass with constant extra space: three 0s, three 1s, three 2s. In quickselect this is the cure for duplicates. A two-way partition on an array of identical values shrinks the range by one element per pass, which is quadratic. A three-way partition removes the pivot's whole band of equals at once, and if the index you want falls inside that band, the answer is the pivot and the search ends. With the pivot fixed at 1, this is exactly Sort Colors.
