@0
Nine numbers: minus 2, 1, minus 3, 4, minus 1, 2, 1, minus 5, 4. We want the contiguous run with the largest sum. Kadane's rule makes one decision at each element: extend the running subarray, or start fresh here. Two numbers carry the state. Current is the best sum of a run that ends right here, and best is the highest current we have ever seen.

@1
The first element starts the run. Current and best are both minus 2.

@2
Next is 1. Minus 2 plus 1 is less than 1 on its own, so the running sum was a burden. Drop it and restart at position 1. Current is 1, and best becomes 1.

@3
Minus 3 extends the run. Current falls to minus 2, and best stays at 1.

@4
Then 4. Minus 2 plus 4 is less than 4, so again the prefix only hurts. Restart at position 3: current is 4, and best is 4.

@5-7
From here the run keeps extending. Minus 1 takes current to 3, but it is still positive, so it is worth keeping. Then 2 makes it 5, and 1 makes it 6. Best follows it up to 6.

@8-9
Minus 5 drops current to 1. That is still positive, so the run extends rather than restarts, and the final 4 lifts it to 5. Neither beats 6.

@10
The maximum subarray sum is 6, from positions 3 to 6: 4, minus 1, 2 and 1. One pass, constant space. You can read this two ways, and both are right. As dynamic programming, current is a one-cell table: the best sum ending here is the larger of this element alone, or this element plus the best ending one step back. As greedy, a prefix with a negative sum can never help, so drop it. Saying that it is a DP with a greedy reason for why the state is one number is the sentence that signals seniority.
