@0
Four nodes, A to D, and one edge is negative: C to B costs minus 3. Dijkstra's proof breaks on that edge, so we use Bellman-Ford. It does not choose a node; it simply relaxes every edge, in a fixed order, round after round, up to V minus 1 rounds, which is 3 here. A starts at 0 and everything else at infinity.

@1-2
Round 1 begins. The edge from A to B sets B to 4, and the edge from A to C sets C to 2.

@3
Next comes C to B, the negative edge. C is 2, so B becomes 2 minus 3, which is minus 1. That beats 4.

@4
Then B to D: minus 1 plus 2 sets D to 1.

Notice what just happened. Within a single round, B was set through a two-edge path, and D through a three-edge path, because this version relaxes in place and reads values written earlier in the same round. For plain shortest paths that is harmless. But the lesson's round invariant, the cheapest path using at most i edges after round i, only holds if every read comes from the previous round's copy. With a limit on stops, as in Cheapest Flights Within K Stops, relaxing in place lets longer paths leak in, and the fare comes out too cheap.

@5
Round 2 relaxes every edge again, and nothing changes, so the distances are final and the loop exits early.

@6
The answer: A 0, B minus 1, C 2, D 1. The cost is V times E. To detect a negative cycle, run one more round: if anything still relaxes, a cycle reachable from the source keeps making paths cheaper, and no shortest path exists.
