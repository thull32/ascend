@0
Here is a grid of four rows and five columns, where 1 is land and 0 is water. An island is a group of land cells joined up, down, left or right. The grid is an implicit graph: every cell is a node, and its four neighbours are its edges. The method is a scan plus a flood fill. Scan the cells in order, and every land cell that has not been visited yet starts a new traversal that marks its whole island.

@1
The scan begins at row 0, column 0, which is land and unvisited. That is island 1.

@2-4
The flood fill spreads from it: the corner itself, then its neighbour to the right at row 0, column 1, then the cell below it at row 1, column 0. Every other neighbour is water, so the fill stops. Island 1 has three cells, all marked.

@5-7
The scan carries on, skipping water and the cells already marked, until row 1, column 3. Unvisited land, so island 2 begins, and the fill takes it and its neighbour at column 4. Two cells.

@8-11
Next is row 2, column 2: island 3. The fill moves down to row 3, column 2, and right to row 3, column 3. Three cells, joined in an L.

@12-13
Last, row 3, column 0 is land that nothing has reached. It sits alone, touching only water, so island 4 is a single cell.

@14
Four islands. The counter only goes up when the scan meets land that no earlier fill reached, so it counts traversals, not cells. Each cell is visited a constant number of times, which makes the whole thing rows times columns. The same skeleton counts connected components in any graph, and writing the mark straight into the grid is the cheapest visited set there is.
