@0
The diameter is the longest path between any two nodes, counted in edges. This tree is 1 at the root with a single right child, 6. Below 6 sit 4 and 8, and each of those has two leaves: 3 and 5 under 4, 7 and 9 under 8. The recursion carries two different quantities. Each call returns its height to the parent, and separately updates a global best with left height plus right height. Keep them apart, because that is the whole trick.

@1-4
Every node needs both children's heights before it can do anything, so the walk is post-order: it goes all the way down first. Enter 1, then 6, then 4, then the leaf 3.

@5
At 3, both children are empty, with height 0. The longest path through 3 is 0 plus 0, which is 0 edges, so the best stays 0. It returns height 1 to its parent.

@6-7
The leaf 5 does the same: nothing through it, and it returns height 1.

@8
Now 4 has both answers. The longest path through 4 is 1 plus 1, which is 2 edges, from 3 up to 4 and down to 5. That beats 0, so the best becomes 2. But the parent can only extend one arm, so 4 returns 1 plus the larger child, height 2.

@9-13
The right side mirrors it. Enter 8, then its leaves 7 and 9, each of which returns height 1 and leaves the best at 2.

@14
At 8 the path through it is again 1 plus 1, 2 edges. That only ties the best, so the best stays 2, and 8 returns height 2.

@15
At 6 both arms are height 2, so the path through 6 is 4 edges, from a leaf under 4 to a leaf under 8. That is the new best, 4. And 6 returns height 3.

@16
At the root, the left arm is empty, so the path through 1 is 0 plus 3, only 3 edges. The best stays 4. Notice the answer did not pass through the root at all, which is why it lives in a side variable rather than in the return value.

@17
The diameter is 4 edges, highlighted from 3 through 4, 6 and 8 to 9. It took one post-order pass, so linear time. Computing a separate height at every node instead is n squared on a chain. The same shape, return one arm to the parent and record both arms on the side, solves maximum path sum and longest univalue path.
