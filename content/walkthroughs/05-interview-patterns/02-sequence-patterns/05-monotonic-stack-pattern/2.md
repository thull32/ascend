@0
Eight values, 9, 4, 7, 2, 6, 1, 3, 8, and a window of size 3 sliding across them. We want each window's maximum. The tool is the decreasing stack from earlier in the lesson, kept in a deque of indices, plus one extra move: evicting the front when its index leaves the window. The invariant: the deque's values decrease from front to back, so the front is always the current window's maximum.

@1-2
Index 0, value 9, goes in. Index 1, value 4, goes in behind it: 9 then 4, still decreasing.

@3-4
Index 2, value 7. Four is at the back and smaller, and 4 can never be a window's maximum while 7, which is newer and larger, is in the same window. So 4 is popped from the back, and 7 is pushed. The deque is 9, 7.

@5
The first window, positions 0 to 2, is complete. Its maximum is the front: 9.

@6-8
Index 3, value 2, is pushed behind 7. But now the window is positions 1 to 3, and the front, index 0, has slid out. It is expired from the front. That is the move the plain monotonic stack never needed. The front is now 7, the maximum of 4, 7 and 2.

@9-11
Index 4, value 6, pops the 2 from the back and is pushed. The deque is 7, 6, and the window from 2 to 4 has maximum 7.

@12-14
Index 5, value 1, joins at the back: 7, 6, 1. Then index 2, the 7, leaves the window and is expired from the front. Window 3 to 5: maximum 6.

@15-17
Index 6, value 3, pops the 1 and is pushed. Deque 6, 3, and the window from 4 to 6 has maximum 6.

@18-21
Index 7, value 8, is larger than everything in the deque. It pops 3, then 6, from the back, and is pushed alone. The last window, 5 to 7, has maximum 8.

@22
The answers are 9, 7, 7, 6, 6 and 8. Each index was pushed once and popped at most once, from one end or the other, so the whole pass is linear, not n times k. Anything larger than the front would have popped it, and anything older has been expired, so the front is always the answer. In JavaScript, use a head index or a ring buffer for the front pops, not shift on a long array.
