@0
Five nodes, 1 through 5, and we must remove the second node from the end, which is 4, in one pass. Two ideas combine. A dummy node sits in front of the head, so removing the head itself would be an ordinary case. And two pointers, slow and fast, both start on the dummy, and fast will be kept exactly two nodes ahead.

@1-2
First, fast walks alone. One step puts it on 1, two steps on 2. Now it is two nodes ahead of slow, which is still on the dummy.

@3-5
Now both move one node per step, so the gap stays two. Slow on 1, fast on 3. Slow on 2, fast on 4. Slow on 3, fast on 5.

@6
Fast is on the tail. Because the gap is two, slow is on 3, the node just before the second from the end. That is the point of the gap: we stop one node early, on the predecessor, which is the node whose link has to change.

@7
Splice: slow's next becomes slow's next's next. Node 3 now points straight to 5, and 4 is unlinked in constant time. No other node moves.

@8
The list reads 1, 2, 3, 5, and the function returns the dummy's next as the head. One pass, linear time, constant space. Now ask for the fifth node from the end, which is the head: fast walks five nodes to the tail, slow never leaves the dummy, and the same splice removes 1. Without the dummy that case needs its own branch, and it is the branch people forget.
