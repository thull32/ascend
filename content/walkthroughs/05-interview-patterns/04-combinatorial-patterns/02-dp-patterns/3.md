@0
Can leetcode be split into dictionary words, when the dictionary holds leet and code? The cell for position i says whether the first i characters can be segmented. It turns true when some dictionary word ends exactly at i, and the prefix before that word is itself breakable.

@1
The base case: the empty prefix is trivially segmentable, so position 0 is true. Every other cell starts false.

@2-4
Positions 1, 2 and 3 hold l, le and lee. No dictionary word ends at any of them, so all three stay false.

@5
At position 4 the word leet ends, and the prefix before it is empty, which is breakable. Position 4 turns true.

@6-8
Positions 5, 6 and 7 add c, co and cod after leet. None of those is a word, so they stay false.

@9
At position 8, code ends, and the prefix before it, leet, is breakable because position 4 is true. So position 8 is true.

@10
The whole string breaks as leet followed by code, recovered by following the recorded split points back to 0. The cost is the length of the string, times the dictionary words tried at each position, times the length of each comparison. Bound the inner loop by the longest word: no word can start further back than that, and on a long string of a's the bound turned millions of checks into a few thousand.
