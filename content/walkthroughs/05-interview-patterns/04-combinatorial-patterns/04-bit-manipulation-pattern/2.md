@0
Every value in 4, 1, 2, 1, 2 appears twice except one. Find it in one pass with no extra memory. XOR has three properties that do all the work: anything XOR itself is 0, anything XOR 0 is itself, and the order does not matter. So XOR the whole array together, and every pair cancels.

@1-3
The accumulator starts at 0. XOR in 4, and it is 4. XOR in 1, and the bits differ in the last column, so it becomes 5, binary 1 0 1. XOR in 2, and it becomes 7, binary 1 1 1. Each new value switches on its own bits.

@4-5
Now the second copies arrive. XOR in 1 again, and the last bit switches back off: 6. XOR in 2 again, and the middle bit switches off: 4. Each second copy undid the first.

@6
The accumulator is 4, the value with no partner. That is linear time, constant extra space, and no hash set. It works in any order, because the accumulator always equals 4 XOR 1 XOR 1 XOR 2 XOR 2, and the pairs cancel wherever they sit. When values appear three times instead of twice, XOR no longer cancels them, and you count each bit column modulo 3 instead.
