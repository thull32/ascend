@0
Three items, 3, 5 and 9, and every subset of them. A three-bit number can name one subset: bit i set means item i is in, with bit 0 the rightmost column, which stands for the 3. Count from 0 up to 2 to the 3 minus 1, which is 7, and you visit all 8 subsets.

@1
Mask 0 is 0 0 0. No bits set, the empty subset.

@2-3
Mask 1 sets bit 0, so the subset is just 3. Mask 2 sets bit 1, so it is just 5.

@4
Mask 3 is 0 1 1: bits 0 and 1, the subset 3 and 5.

@5-7
Mask 4 sets bit 2, which is 9 alone. Mask 5 is 1 0 1, bits 2 and 0, so the subset is 3 and 9. Mask 6 is 1 1 0, which is 5 and 9.

@8
Mask 7 is 1 1 1, every bit set: the full set.

@9
All 8 subsets in 2 to the n steps. The counter replaces the backtracking tree's include-or-exclude recursion, and a mask is a single integer, so it is a cheap, hashable key for memoising on a subset. One more property makes it ideal for subset dynamic programming: every proper subset of a mask is numerically smaller, so going through masks in increasing order always solves the smaller subsets first.
