@0
We want every subset of 1, 2 and 3. This version makes one decision per level of the tree: include this element, or leave it out. Three elements, two choices each, so the tree is binary and has 2 to the power 3, which is 8, leaves. Every leaf is one subset.

@1-3
The search always tries include first. Include 1, include 2, include 3. Each call extends the same path by one choice.

@4
All three decisions are made, so the path is a complete answer: record 1, 2, 3 as subset number 1.

@5-7
Now backtrack. Undo the last choice, take the exclude branch for 3, and record 1, 2 as subset number 2. Both branches under 1, 2 are done, so return to the parent.

@8-12
Back at the path holding just 1, now exclude 2. Include 3 gives 1, 3, subset number 3. Exclude 3 gives 1 alone, subset number 4.

@13-15
Everything that starts with 1 is finished. The calls unwind to the root, the empty path, and take the exclude branch for 1.

@16-21
The same shape repeats one level down. Include 2, include 3: record 2, 3. Exclude 3: record 2.

@22-26
Then exclude 2 as well. Include 3 gives 3 alone, subset number 7, and excluding everything gives the empty set, subset number 8.

@27-29
The remaining calls return, each with both branches explored, until the root is done.

@30
8 subsets from 15 calls, and both the empty set and the full set are leaves. The cost is 2 to the n answers, each up to n long to copy, with a stack only n deep. The template in the lesson uses a start-index loop instead, which records every node as an answer and produces the same 8 subsets. Either way, the move that makes it backtracking is the undo: choose, recurse, then remove the choice before trying the next one.
