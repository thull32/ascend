@0
Repeated squaring computes x to the power n with one multiplication into the result for every set bit of n. So it helps to see exactly which bits of 13 are set. The visualiser finds them with Kernighan's trick: n AND n minus 1 clears the lowest set bit, one step per set bit.

@1
13 is 1 1 0 1 in binary: bits 0, 2 and 3 are set. The count starts at 0.

@2-3
The lowest set bit is bit 0. Subtracting 1 flips just that bit, and the AND clears it, leaving 12. In pow of x to the 13, that bit is worth x to the 1: the first factor multiplied into the result.

@4-5
Next, bit 2. The borrow runs through the zero at bit 1, and the AND clears bit 2, leaving 8. That bit is worth x to the 4.

@6-7
Last, bit 3. Clear it, and nothing is left. That bit is worth x to the 8.

@8
Three steps, three set bits. And x to the 13 is x to the 1, times x to the 4, times x to the 8: one factor per set bit, exactly the three multiplications into the result.

@9
The four bit positions of 1 1 0 1 are the four loop iterations, and each one squares x, whether or not its bit is set. With x equal to 2, the result goes 2, then 2 again because bit 1 is 0, then 32, then 8192, which is 2 to the 13. That is about 32 iterations for any exponent up to 2 to the 31, instead of 2 billion multiplications.
