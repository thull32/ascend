@0
Eight values: 3, 1, 4, 1, 5, 9, 2 and 6. Below them is the prefix array P, one slot longer than the input, built exactly as the template's accumulate with an initial 0 builds it. Its first entry is already there: P of 0 is 0, the sum of no elements. From then on, P of i plus 1 is P of i plus the next value, so P of i is always the sum of the first i elements.

@1-4
Each step is one addition. 0 plus 3 is 3. 3 plus 1 is 4. 4 plus 4 is 8. 8 plus 1 is 9. The index of each entry counts how many elements it has consumed, which is the one convention the lesson asks you to pick and keep.

@5-8
The rest follow the same way: 14, 23, 25, and finally 31, the sum of the whole array, in P of 8. One pass, linear time.

@9
Now a query that starts at the very beginning: the sum of indices 0 to 3, which is 3, 1, 4 and 1. The formula is P of j plus 1 minus P of i, so P of 4, which is 9, minus P of 0, which is 0. The answer is 9. That is the payoff of the leading zero: a range starting at index 0 needs no special case, and every query is the same single subtraction. Build once in linear time, then answer each query in constant time, which is exactly the shape of Range Sum Query.
