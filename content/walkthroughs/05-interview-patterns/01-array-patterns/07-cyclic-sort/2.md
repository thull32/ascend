@0
The problem is Missing Number on the array 3, 0 and 1, where the values should cover 0 to 3. The table lists that array followed by the full range 0, 1, 2 and 3, seven numbers in all, each shown in four bits. An accumulator starts at 0. The idea rests on two facts about exclusive or: a value combined with itself gives 0, and a value combined with 0 is unchanged. Order does not matter. So every number that appears twice will cancel, and the one that appears once survives.

@1-2
Each step lines up the accumulator's bits with the next value's bits: where the two bits differ the result is 1, where they agree it is 0. Zero combined with 3 is 3. Then 3 combined with 0 is still 3.

@3-4
Three with 1: the lowest bit flips off, leaving 2. Then 2 with 0 stays 2. That finishes the array; the range begins.

@5
Two with 1 sets the lowest bit again, giving 3. The 1 from the array and the 1 from the range have cancelled.

@6
Three with 2 clears the second bit, leaving 1. The 2 enters only once.

@7
And 1 with 3 gives 2. The two 3s have cancelled, and so have the two 0s.

@8
The accumulator ends at 2, the only value that appeared an odd number of times, so 2 is the missing number. Linear time, constant extra space, no hash set and no mutation of the input. With one unknown and distinct values this is the answer to offer first. Cyclic sort earns its place when the follow-up asks for every missing number, or adds duplicates, where one equation no longer pins down the answer.
