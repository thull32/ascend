@0
Eight values: 1, 2, 3, 1, 2, 4, 3 and 5. We want the longest stretch with no repeated value. This is the longest shape of the window: the right edge admits one element per step, and the left edge moves only when the window has become invalid. The invariant: after each step, the window is the longest valid one ending at the right edge.

@1-3
The first three values, 1, 2 and 3, are all new. The window grows to three, and the best is 3.

@4
Then a 1 arrives, and the window already holds a 1, at position 0. The left edge jumps just past it, to position 1. The window is 2, 3, 1: still three long, all distinct.

@5
A 2 arrives, and the old 2 sits at position 1, so the left edge jumps to 2. The window is 3, 1, 2.

@6
A 4 is new, so the window grows to four: 3, 1, 2, 4. The best is 4.

@7
A 3 arrives, and the old 3 is at position 2. The left edge jumps to 3, leaving 1, 2, 4, 3: four long, still the best.

@8
Finally a 5, new, and the window grows to five: 1, 2, 4, 3, 5. The best is 5.

@9
The answer is 5. Notice that the left edge only ever moved right. Each pointer crosses the array at most once, so the whole scan is linear, even though some steps moved the left edge by more than one. That monotone left edge is the property to check before reaching for a window: it holds here because shrinking a window with no repeats can never create one.
