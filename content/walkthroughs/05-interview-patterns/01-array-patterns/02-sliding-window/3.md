@0
The text is c b a e b a b a c d, and we want every place where some arrangement of a b c appears. Count the pattern's characters once: one a, one b, one c. A window of three text characters is an anagram exactly when its counts equal those.

@1-3
Fill the first window: c, then b, then a. Its counts are one of each, equal to the pattern's, so c b a at position 0 is an anagram.

@4
Now the window slides: drop c, add e. The counts for c and e are off, so this is not an anagram.

@5-8
Keep sliding, one character in and one out. Drop b, add b. Drop a, add a. The e is still inside, so neither window matches. Then the e leaves and a b arrives, but now there are two b's and no c. Another slide, and there are two a's and still no c.

@9
Drop a, add c: the window is b a c, one of each. A second anagram, at position 6.

@10
The last slide drops b and adds d, which is not in the pattern at all. No match.

@11
Anagrams start at positions 0 and 6. Every character entered the window once and left it once, and each slide changed just two counts, so the scan is linear in the text, with a count table the size of the alphabet. The lesson's matches counter goes one step further: it tracks how many characters currently have the right count, so checking a window costs constant time instead of a pass over the alphabet.
